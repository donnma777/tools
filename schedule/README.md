# 配信スケジュールメーカー

1週間（または1か月）の配信予定から、SNS に載せるスケジュール画像を作るツールです。OBS のブラウザソースに入れると、今日の予定を目立たせて配信画面にも出せます。

| ファイル | 内容 |
|----------|------|
| `index.html` | 作るページ。予定・文字・見た目を決めて、PNG で保存・コピー。OBS 用の URL を出し、OBS につないで反映もできる |
| `view.html` | OBS に入れるページ（noindex）。中身はすべて URL の `d=` から読む |
| `schedule-core.js` | 描く処理（`window.ScheduleCore`）。両方のページで同じ絵を canvas に描く |

## できること

- **1週間**：最初の日を選ぶ（◀ 今週 ▶）。週のはじまりは月曜・日曜。週を変えても予定は曜日の順のまま残る
- **1か月**：月を選ぶ（◀ 今月 ▶）。カレンダーの形で描く。編集はカレンダーの日を押して、その日の予定を入れる（予定は日付ごとに覚え、2か月より前のものは月を変えたときに消す）。「週の予定から入れる」で、1週間のほうの曜日ごとの予定を、まだ何もない日に入れる。タイトルがはじめのままなら、切り替えで WEEKLY ↔ MONTHLY も変える
- **予定**：1日に 3 つまで「時刻・種類・内容」。内容は複数行（4行まで。textarea は行に合わせて高くなる）。お休み、前の日と同じにする。種類はよく使うもの（ゲーム・雑談・歌・コラボ・企画・ASMR・作業・告知）から選ぶか自由に書く。色は種類ごと（決まっていない言葉は言葉から色を作る）
- **文字**：タイトル・名前・お知らせ、曜日（日本語／英語）、時刻のあとの「〜」
- **見た目**：ポップ・シンプル・ネオン・和風、色。大きさは横長 16:9（1920×1080）・縦長 4:5（1080×1350）・正方形（1080×1080）・縦長 9:16（1080×1920）。背景はテーマ・画像・透明
- **キャラの画像**：ファイル（縮めて localStorage に覚える）か URL。横長は右の列に全身、縦長は見出しの右に上半身
- **保存**：PNG・クリップボードに画像をコピー
- **OBS**：今日の予定を目立たせる（枠と TODAY）・過ぎた日を薄くする。1分ごとに描き直すので、日付が変わると切り替わる
- **OBS につないで反映**：obs-websocket v5。時計・経過時間（`clock/`）と同じ作り。ソースを選んでも、その中身はこちらに読み込まない（ここで作った予定を優先）。はじめは「ボタンで反映」

## URL（`view.html`）

- `d`：中身の JSON（`ScheduleCore.normalize` の形）を `forUrl` で絞り（1週間なら `mdays` なし、1か月ならその月の `mdays` だけで `days` なし）、UTF-8 → base64url にしたもの。1週間で 2KB、1か月で 5KB くらい
- `today=YYYY-MM-DD`：「今日」を決める（確かめる用）
- 画像のファイルは URL に入らない。キャラは `chara`（https の URL）だけ OBS に出る。背景の画像は OBS では出ない（テーマの柄になる）

## 開発メモ

- 字体は Google Fonts（Zen Maru Gothic・Zen Kaku Gothic New・Dela Gothic One・Shippori Mincho B1）。canvas は読み込みを待たないので、`ensureFonts` で使う字を指定して読み込んでから描き、`document.fonts` の `loadingdone` でも描き直す。
- 設定は localStorage（`donnma-schedule`、画像は `donnma-schedule-img`、OBS は `donnma-schedule-obs`）。
- URL の画像は CORS ありで読み、だめなら CORS なしで見本にだけ出す（そのときは保存できないので、知らせる）。
- テーマを足すときは、`THEMES`・`palette`・`drawBackground` と、行の飾り（`draw` の中の theme ごとの分かれ）に足す。
