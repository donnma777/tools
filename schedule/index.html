見本

📺 OBS に出す

↗ 開く

🔌 OBS につないで反映つないでいません

OBS の「ツール → WebSocket サーバー設定」で、サーバーを有効にしてから使います。つなぐと、ここで変えた予定や見た目を、URL を貼り直さずに OBS に反映できます。

🔍使い方
  1. 1週間・1か月・時間割・1日から作るものと、いつの予定かを選び、日ごとに時刻・種類・内容を入れます（内容は改行もできます）。配信しない日は「お休み」にチェック。1か月は、カレンダーの日を押して入れます。
  2. 文字と見た目（テーマ・色・大きさ・背景・キャラの画像）を選びます。右の見本がすぐ変わります。
  3. 「⬇ PNG で保存」で画像にして、X などに載せます。「📋 画像をコピー」なら、そのまま貼り付けられます。
  4. OBS に出すときは「📋 URL をコピー」を押し、OBS で ソースを追加 → ブラウザ の URL に貼ります。幅・高さは URL の下に出ている大きさにします。
  5. OBS では、今日の予定が目立ち、過ぎた日が薄くなります（日付が変わると自動で切り替わります）。1日の進行表なら、今の枠に NOW と残り時間、次の枠に始まるまでの時間が出ます。予定を変えたら、URL を貼り直すか、OBS につないで反映してください。
📐大きさの選び方
  • 横長 16:9（1920×1080）：X にそのまま大きく出て、OBS の配信画面にもぴったりです。迷ったらこれ。
  • 縦長 4:5（1080×1350）：X や Instagram で、タイムラインに縦に大きく出ます。スマホで見る人が多いとき向け。
  • 正方形（1080×1080）：Instagram の投稿や、どこでも崩れずに出したいとき。
  • 縦長 9:16（1080×1920）：Instagram・X のストーリーや、YouTube のショート向けです。
💡ヒント・注意点
  • 入れた予定・見た目・選んだ画像は、このブラウザに覚えておきます。来週は「▶」で週を進めて、変わったところだけ直せば作れます。
  • 画像はどこにも送信しません。キャラの画像は、背景を透明にした PNG がきれいに出ます。
  • OBS の URL には予定と見た目が入っています（ログインや保存は要りません）。画像のファイルは入らないので、OBS でキャラを出したいときは、画像の URL を入れるか、OBS で画像のソースを重ねてください。
  • 背景を透明にすると、OBS で好きな背景や配信画面の上に重ねられます。
  • OBS では、OBS を動かしているパソコンの日付で「今日」を決めます。
