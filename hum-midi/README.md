# 鼻歌 MIDI 変換

マイクで歌った鼻歌や楽器の音、音声ファイルから音の高さを読み取って、MIDI ファイル（.mid）にするツールです。音はどこにも送りません。

| ファイル | 内容 |
|----------|------|
| `index.html` | 画面と処理（1ファイル。外部のライブラリは使わない。確認は `../common/ask.js`） |
| `mp4-muxer.js` | 動画（MP4）を組み立てる部品 [mp4-muxer](https://github.com/Vanilagy/mp4-muxer) 5.2.2（MIT、`mp4-muxer-LICENSE.txt`）。動画を作るときだけ読み込む |
| `lame.min.js` | MP3 を作る部品 [lamejs](https://github.com/zhuker/lamejs) 1.2.1（LGPL-3.0、`lamejs-LICENSE.txt`。手を入れずにそのまま置く）。MP3 で書き出すときだけ読み込む |
| `guide/index.html` | 説明書（`/tool/hum-midi/guide/`）。使い方はここに書き、ツールの画面には細い見出しの「📖 説明書」と VOICEVOX の「くわしい手順」のリンクだけ置く |

## できること

- **マイクを聞く**（`MON`）：録らずに AnalyserNode（2048）を 50ms ごとに 16kHz に間引いて `yinPitch()`、3つの中央値。今の音を鍵盤に黄色と横線、0.2 秒続いた音で音域（`S.monLo`・`S.monHi`）を広げて左に緑の帯（`drawMonitor()`）。録音の間は止めて、終わると `S.monitor` なら戻す。開いたときマイクが許可済みなら自動で聞く。確かめは Chrome の `--use-file-for-fake-audio-capture=wav`（フェイクのマイクの音は 3〜5kHz のピッという音で、声の高さは出ない）
- **マイクの大きさ**：`micGain`（0〜+24 dB。onChunk で掛けて tanh で抑える）、`micAgc`（getUserMedia の autoGainControl）。録音中に直近3秒の最大が -42 dB より小さいと「🔈 小さい」。音声のトラックは録ったあと `normalizeRec()`（最大 0.5 未満なら -1dB まで、16 倍まで）
- **録る**：マイクを選んで録音（10分まで）。テンポ・拍子・カウント（なし／1小節／2小節）・クリックの大きさ。録音中は今の音の名前・ずれ（セント）・入力の大きさを出す
- **開く**：音声ファイル（wav・mp3・m4a・ogg・動画など、ブラウザが読めるもの）をボタンかドロップで
- **変換の設定**：音の高さの範囲（声・低い声・高い声・広く）・拾う基準・小さい音を無視（dB）・いちばん短い音・同じ高さを出だしで区切る・音程のずれの自動合わせ
- **整える**：スケールに寄せる（メジャー・マイナー・ペンタ）と調の推測・オクターブ・クオンタイズ（4〜32分、3連）と長さ・ベロシティ（声の大きさ／一定）・1小節目の頭（クリック／最初の音／録音のはじめ）・ずれ補正
- **トラック**：メロディ・ドラムのトラックを 16 まで。名前・音色・音量・ミュート・ソロ。再生は全トラックいっしょ、ほかのメロディはピアノロールにうすく出す。録音中にほかのトラックを鳴らせる（重ね録り）
- **音色**：ピアノ・エレピ・オルガン・ストリングス・ギター・ベース・シンセリード・8bit・フルート・ベル・シンプル（WebAudio で合成。.mid には GM の番号を入れる）
- **ドラム**：クリックで置く・ダブルクリックで消す。録音すると口ドラムを読み取って、キック・スネア・ハイハット（閉）に分ける。音は WebAudio で合成（11 種）
- **ピアノロール**：読み取った音の高さ（点）と MIDI の音（四角）。ドラッグで高さ・位置・長さ、ダブルクリックで追加、Delete・右クリック（なぞると続けて）で削除、囲んで・Ctrl+クリック・Ctrl+A でまとめて選ぶ、矢印キー、Ctrl+C／X／V・Ctrl+D（複製）、Ctrl+Z／Ctrl+Y（トラックごと）、Ctrl+ホイールで横の幅
- **キーボード入力**（K）：Z〜/ が下の段・Q〜P が上の段（ピアノの並び）、ドラムは Z キック・X スネア・A ハットなど。止まっているときは押すと再生位置に置き、離すと「長さ」だけ進む（同時押しは同じ位置、Tab で休み、Backspace で1つ戻して消す）。再生中は押していた長さで入る。− ／ ＾ でオクターブ
- **テンプレート**：① 伴奏（コード進行9種・調・ドラム7種・伴奏の形・4/8/16小節。伴奏・ベース・ドラム（auto `tpldrum`）と空のメロディのトラックを作り、録音中にほかのトラックを鳴らすをオン）② ドラム1小節（再生位置の小節を入れ替えて次の小節へ）③ 見本の曲（オリジナル。そらをみて＝4/4・C、あかいそら＝3/4・G、VOICEVOX アカペラ＝そらをみてを4人の声だけで。VOICEVOX につながればずんだもん（アカペラは＋四国めたん・春日部つむぎ・玄野武宏）、つながらなければ合成の声）。ハモリを作るとき、元が VOICEVOX なら別のキャラにする。コードの候補はその調のコードから
- **読み込み**：.mid（フォーマット 0・1。チャンネルごとにトラックへ、10ch はドラム、音色は GM の番号から、歌詞・テンポ・拍子も）。ボタンかドロップで
- **録音を残す**：IndexedDB（`donnma-hum-midi` の `audio`、16bit）。開き直すと読み戻して読み取りもやり直す
- **強さの欄**：ピアノロールの下。なぞると強さ（Shift で選んだ音全部）。**まとめて**：つなげる・短く切る・長さ ½・×2・強さ ±（選んだ音、なければ全部）
- **テンポを当てる**：クリックなしの録音で、音の出だしを8分のグリッドに合わせて BPM（60〜180、110 あたりを少し優先）と1小節目の頭を出す
- **MIDI 入力**：Web MIDI。入れ方はキーボード入力と同じ（ドラムは近い GM の番号に寄せる）
- **文字で入力**：ドレミ・do re mi・CDEFGAB、# b、ー（のばす）、・ r（休み）、^ _（オクターブ）、数字（C5 など）。高さは前の音に近いほう
- **音符の上で歌詞**：音符をダブルクリック（か選んで Enter・F2）で入力欄。Enter で決める、Tab／Shift+Tab で次・前の音符、まとめて打つと後ろの音符へ流し込む（`splitLyrics`）。歌詞は音符の中に出し、歌う音色で歌詞のない音符には薄く「ら」
- **歌詞**：かなは1文字ずつ（小さい字はまとめる）、ほかは1語ずつ音に入れる。.mid には歌詞（FF 05。Shift_JIS か UTF-8、Shift_JIS にできない字は UTF-8）
- **歌声ソフトへ**：.ust（UST 1.2、480 分解能、すき間は R、「ー」は前の母音、「っ」は R、Shift_JIS・CRLF）、MusicXML、歌詞入り .mid。VOCALOID（.vpr・.vsqx）や Synthesizer V（.svp）は UtaFormatix（https://sdercolin.github.io/utaformatix3/）で変換してもらう（VOCALOID の形式は歌声ライブラリの ID などが要り、ここでは確かめられないので直接は作らない）
- Shift_JIS：かなは計算、漢字などはブラウザの TextDecoder('shift_jis') から逆引きの表を1回作って使う（`sjisMap()`）
- **VOICEVOX の歌声**：パソコンで動く VOICEVOX エンジン（既定 `http://127.0.0.1:50021`、0.16 より新しいもの）に、音を1つずつの並び（休みは key なし、時間は 93.75 フレーム/秒、頭に 15 フレームの休み）にして送り、先生役（type `sing`、ふつう 6000）の `/sing_frame_audio_query` → 選んだ声（type `frame_decode`）の `/frame_synthesis` で WAV を作る。再生・書き出しの前に、音と声が変わっていたら作り直す（`vvFresh`）。歌詞の「ー」は前の母音、かな以外は「ら」（VOICEVOX は受け付けない）。使うには VOICEVOX のエンジン設定（`/setting`）の Allow Origin に `https://donnma.com`（file:// なら `null`）を足して起動し直す（初期の localapps では 403）。つながらないときは合成の声で鳴らす
- **歌（合成の声）**：のこぎり波を3つのフォルマントに通して母音、子音はノイズ。歌詞がないところは「ら」
- **コード伴奏**：調（スケールの設定か当てた調）の3和音から、メロディの音の入り方とつながりの良さで Viterbi。伴奏（白玉・4分・アルペジオ）とベースのトラックを作る。コード名クリックで候補を替える。.mid にはマーカー（FF 06）
- **ハモリ**：調に合わせて3度上・下・6度下・5度上・オクターブ。歌詞も写す
- **楽譜**：16分にそろえて五線譜（SVG。調号・臨時記号・タイ・歌詞・コード名）。印刷と MusicXML 4.0。**クリックで入力**：長さ（全〜16分・付点）・休符・臨時記号（調どおり／♯／♭／♮）を選んで五線をクリック（その長さの所の音は入れ替え、和音オンなら重ねる）。音符クリックで選ぶ、右クリックで消す。最後に空の小節を1つ出す。描くときにクリック位置を引く表（`scoreMap`：段・小節・音符の x と 16分の位置）を作る
- 調を当てるのは音が12個以上のときだけ（少ないと楽譜の調号がころころ変わるので、それまでは C）
- **AI**：曲を JSON（時間は拍、音は C4 のような名前、ドラムは kick などの名前、歌詞・コードつき）にしたプロンプトをコピーして、ほかの AI に頼み、答えを貼って反映する（送ったトラックと入れ替え／トラックを追加）。答えの ```json の中か { 〜 } を読み、末尾のカンマやコメントは直し、読めない音は飛ばして数を出す
- **トラックの「和」**：和音を使う（オフだと重なりを前の音を短くして1音ずつに）
- **再生**：最初から（Home）・再生と停止（Space）・リピート（L。目盛りをドラッグで範囲、右クリック・ダブルクリックで解除）。録音と MIDI を重ねて、クリックも
- **書き出し**：.mid（フォーマット 1・480 分解能。1つ目にテンポ・拍子・調号、あとはトラックごとに音色・音量。ドラムは 10ch）、声の録音（選んだトラックの .wav、16bit モノラル）、音で書き出す（全トラックを OfflineAudioContext で鳴らした .wav、44.1kHz・2ch。声を混ぜるかは選べる。割れそうなら下げる）
- **曲の保存・呼び出し**：ピアノロールの見出しの「🎵 曲の名前」でダイアログ（`#song-dlg`）。タイトル・作詞・作曲・編曲・メモ（`meta`）。保存は IndexedDB の `songs`（keyPath `id`。`{ id, meta, created, updated, bpm, beats, song: songData(), audio: [{ uid, sr, pcm, … }], stats }`）。上書き・別の曲として保存・新しい曲・開く・消す・さがす。Ctrl+S で保存（未保存ならダイアログ）。変更ありの ● は、保存したときの中身の値（`songSig()`：トラック・コード・meta・テンポ・拍子の FNV ハッシュ）と比べる
- **AI のタブのファイル**：「⬇ JSON を保存」は送る範囲（aiScope）を `saveNotesJson()` でファイルに（aiSent も決める）、「⬆ JSON ファイルを開く」は中身を答えの欄に入れて `applyAi()`（送ったトラックと置き換え／トラックを追加）
- **音で書き出す**：「その他の保存 ▾」→ `#aud-dlg`。`renderMix()` を範囲で切り出して割れないように下げ（`audSlice()`）、WAV（`wavFrom()`）・M4A（WebCodecs の AAC ＋ mp4-muxer の音だけの MP4）・MP3（lamejs）・FLAC（自前の `FLAC.encode()`：16bit・4096 ずつ・固定予測 0〜4 次・ライス符号・左右／ミッド・サイドの小さいほう。MD5 は 0）。FLAC は Chrome で読み戻して元と1サンプルも違わないことを確かめてある（Chrome は正の値を 1/32767 で float にする）
- **音声のトラック**（kind `audio`）：MIDI にしない音のままのトラック。録音（読み取りはするが音符は作らない：`buildFor()` が空）か音声ファイル（読み取らずに raw へ）。位置は `audioOff`（1小節目の頭が録音の何秒目か。`origin()` はこれだけを見る）で、波形のドラッグで変える（グリッドに合わせる、Alt で自由）。鳴らすのは `trackEvents()`（`audioBufOf()`）なので、再生・録音中のほかのトラック・`renderMix()` に自然に入る（「録音だけ」でも鳴る。書き出しの「声」はメロディの録音のこと）。波形は `wavePeaks()`（1/400 秒ごとの最大）と `drawWave()`。音符を置く操作（キー入力・MIDI 入力・文字・歌詞・楽譜）は止める。「→ MIDI」（`audioToMidi()`）は raw を写したメロディのトラックを `t0Metro = audioOff` で作る。曲の保存では「録音を残さない」でも音声のトラックの音は残す
- **動画にする**：「その他の保存 ▾」→ `#video-dlg`。`vdModel()`（範囲・トラック・歌詞の行）と `vdDraw()`（1コマ。タイトル・作詞作曲・流れるピアノロール・コード・カラオケの歌詞・進み具合）。形 横 1280×720／縦 720×1280／正方形 720×720（1080p は ×1.5）、色は夜・昼。WebCodecs の VideoEncoder（H.264、avc1.640028 から順に試す）と AudioEncoder（AAC 192kbps）、音は `renderMix()` を範囲で切り出す。mp4-muxer で fastStart の MP4。30fps、コマは 1 枚ずつ（再生しないので曲より早い）。X へは intent（文と URL）を開くだけ、`navigator.share` で動画を渡せるときは 📤 共有も
- **JSON（AI・ほかのツール用）**：「その他の保存 ▾」。AI の「データ（JSON）だけコピー」と同じ形（`songJson()`）を全部のトラックでファイルに。title・lyricist・composer・arranger があれば頭に足す。読み戻しは `openJsonFile()`：「MIDI を開く」「曲ファイル・JSON を開く」・画面に落とす、のどれでも。`app` があれば曲ファイル、なければ `readAiSong()` で読んで `putSong()`（AI の反映と共通）。置き換えなら新しい曲として title などを使う（なければファイル名）
- **全部の曲の ZIP**：「全部の曲を書き出す（.zip）」は保存した曲を1曲ずつ曲ファイル（`songFileObj()`、libId・作った日つき）にして自前の `ZIP.make()`（CompressionStream の deflate-raw、UTF-8 の名前）でまとめる。「開く（.json・.zip）」や画面に落とした .zip は `importZip()` で一覧に入れる（同じ libId があれば上書き／別の曲として足すを聞く）。Python の zipfile で CRC まで確かめてある
- **曲ファイル**（.json、`app: 'donnma-hum-midi'`）：同じ中身を1ファイルに。録音は base64。開くと未保存の曲として入る
- タイトル・作詞・作曲は書き出しにも：.mid は FF 03（曲名）と FF 01（「作詞：〜」など）、MusicXML は work-title・movement-title・creator、.ust は ProjectName、楽譜の上（`scoreMetaHtml()`。印刷にも出る）。ファイル名もタイトルから
- 設定は localStorage（`donnma-hum-midi`）、作りかけの曲は `donnma-hum-midi-song`（拍で。meta・libId・savedSig も）に残す。録音は IndexedDB の `audio`（作りかけの曲のトラックの uid ごと）

## 開発メモ

- 読み取り：入力を 16kHz 前後に落とし（窓つき sinc で低い音だけ通してから間引く）、10 ミリ秒ごとに YIN で音の高さとゆらぎ（aperiodicity）を出す。範囲を変えたときだけ読み取りからやり直し、それ以外の設定は1コマごとの結果から音を作り直すだけ。3分の音で1秒かからない。
- 音の区切り：前後2コマの中央値でならし、今の音の平均から 0.7 半音より離れた状態が 30 ミリ秒続いたら次の音。音量が直前から 6dB 上がったところと、声が一瞬とぎれたすぐあとも区切る。短すぎる区切り（しゃくり）は後ろの音にくっつける。
- 自動の音程合わせ：半音からのはみ出しを円の上で平均して全体をずらす。
- 時間は、録音のあるトラックは録音の秒、録音のないトラック（手で置いた・開き直した）は拍で持つ（`toBeat()`・`toTime()`）。拍への変換（`origin()`）とクオンタイズは見せるとき・書き出すときにする（`viewNotes()`）。録音のあるトラックはテンポや頭の位置を変えても録音とずれない。頭の位置・ずれ補正・オクターブはトラックごと。
- 口ドラム：音量が直前 40 ミリ秒から 10dB 以上上がったところを叩いたところとし、波形で出だしを探してから 40 ミリ秒の「200Hz より下の割合」（0.4 より上でキック）と「0 をまたぐ割合」（0.3 より上でハイハット、ほかはスネア）で分ける。
- 書き出しは `audio()` が返す先を一時的に OfflineAudioContext（`RC`）に替えて、再生と同じ `trackEvents()` で全部の音を一度に置く。
- 鳴らす音は先読み（0.2 秒）で置いていく（`sequencer()`）。長い曲でも一度に音を作らない。再生は1回分（pass）ずつ予定を作り、リピートのときは終わる 0.3 秒前に次の回をちょうど続く時刻に置く（`schedulePass()`）。
- キーボード入力は `e.code`（キーの位置）で読むので、日本語の配列でも同じ並び。押している音は `voice()` の `release()` で離したときに消す。
- 録音は AudioWorklet を blob → data URL の順で読み、ファイルを直接開いたとき（file://）など読めなければ ScriptProcessor で受ける。
- 録音は AudioWorklet（ページの中に文字列で持つ）で受ける。クリックはノイズを帯域で絞った音（音の高さとして拾われにくい）。クリックで録ったときの頭の位置は、AudioContext の時刻と録音のフレーム番号から出し、出力の遅れ（`outputLatency`＋`baseLatency`＋10ms）を足す。
- 合成した音（ビブラート・しゃくり・ずれ・ノイズ入り）で、高さ・位置・区切りが合うことを確かめてある。`window.__humMidi` から中身をさわれる。
