登録者数カウンター・目標ゲージ（OBS用）

YouTubeの登録者数を自動で取得して、OBSにおしゃれに表示できます。「目標まであと○人」のゲージも出せます。見た目はプレビューを見ながら決められます。

プレビュー
接続設定・OBSに貼るURL

APIキーは、このブラウザとコピーしたURLの中にだけ保存されます。URLにキーが入るので、配信画面やSNSに映さないでください。APIキーの作り方は下の「使い方」にあります。

🎥 OBSでの使い方

  1. 下の「APIキーの作り方」で APIキー を用意します（無料・最初の1回だけ）。
  2. 右の「接続設定」に APIキー と チャンネル（@ハンドル か UC… のチャンネルID）を入れて、「接続テスト」。チャンネル名と登録者数が出ればOKです。
  3. このページで見た目を決めて 「URLをコピー」。
  4. OBSで ソース ＋ → ブラウザ を追加し、URLに貼り付けます。幅 800・高さ 300 くらい（目標ゲージを出すなら高さ 400 くらい）が目安です。カスタムCSSは空のままでOKです。
  5. あとで見た目を変えたときは、もう一度「URLをコピー」して、ブラウザソースのURLを貼り替えてください。

🔑 APIキーの作り方

  1. Google Cloud コンソール にGoogleアカウントでログインし、新しいプロジェクトを作ります（名前は何でもOK）。
  2. 「APIとサービス」→「ライブラリ」で YouTube Data API v3 を検索して、「有効にする」。
  3. 「APIとサービス」→「認証情報」→「認証情報を作成」→ 「APIキー」。
  4. できたキーの編集画面で制限をかけます。「APIの制限」は「YouTube Data API v3」だけを選び、「アプリケーションの制限」は「ウェブサイト」にして https://donnma.com/* を追加して保存。
  5. キーをコピーして、右の「APIキー」に貼り付けます。クレジットカードの登録はいりません。

💡 ヒント・注意点

  • YouTubeの仕様で、APIで取れる登録者数は 1,000人を超えると上から3桁に丸められます（例: 12,345人 → 12,300人）。表示もその数になります。
  • 登録者が増えてから、APIの数が変わるまで少し時間がかかることがあります。
  • 1回数を取りに行くと、APIの使用量を1使います。無料で使えるのは1日10,000までなので、10秒ごとでも足ります。同じキーをほかのツールでも使うなら、30秒以上がおすすめです。
  • OBSのブラウザソースで「表示されていないときにソースをシャットダウンする」をオンにすると、使っていないあいだは数を取りに行きません。
  • 目標ゲージは「🎯 目標ゲージ」でオンにします。目標を超えたら、次のキリのいい数（1,000 → 2,000 → 3,000 → 5,000…）に自動で切り替えることも、「達成」を出したままにすることもできます。プレビューの「🎉 達成を試す」で、超えたときの動きを確認できます。
  • 1,000人を超えると登録者数が上から3桁に丸められるため、ゲージも少しずつではなく、まとまって進みます。
  • うまく取れないときは、カウンターの左上に理由が出ます。
  • 設定はこのブラウザに自動で保存されます。「設定をファイルに保存」にはAPIキーは入りません。
