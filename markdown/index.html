マークダウンメーカー

Markdown を書きながら、すぐ見た目を確かめられます。ボタンで見出しや表を入れたり、Web ページの文章を貼って Markdown にしたりできます。書いたものはどこにも送信しません。

▦表をつくる
横（列）3 縦（行）3
1行目は見出しになります。列の上のボタンで、左・真ん中・右よせを選べます。Excel やスプレッドシートでコピーした表は、ます目に貼り付けるとそのまま入ります。
🔗リンクを入れる
🔍使い方
  1. 左に Markdown を書くと、右にできあがりの見た目がすぐ出ます。記号を覚えていなくても、上のボタンで見出し・太字・リストなどを入れられます。
  2. Markdown を知らなくても、右の見た目の欄に直接 Word のように書けます。書いたところは Markdown になって左に入ります。上のボタンは、最後に触った側（左か右）に効きます。
  3. 表は「表」ボタンから、ます目に書いて作れます。表の中で押すと、その表を直せます。Excel の表は、そのまま左に貼り付けても表になります。
  4. Web ページ・Word・Google ドキュメントの文章を貼ると、見出しやリンクを Markdown にして入れます。
  5. できたら「.md で保存」か、コピーして使う先に貼ります。書いている途中のものはブラウザに覚えておくので、閉じても続きから書けます。
📝書き方の早見表
見出し# 大 ## 中 ### 小（# のあとに空白）
太字・斜体**太字** *斜体* ~~取り消し~~
箇条書き- 項目、番号は 1. 項目。前に空白を入れると1段下がる
チェック- [ ] まだ - [x] 済み
リンク[文字](https://…)
画像![説明](https://…/画像.png)
引用> 文
コード`短いコード`、かたまりは ``` の行ではさむ
区切り線---（前に空の行）
改行段落を分けるときは空の行。段落の中で改行するときは、行の終わりに空白を2つ（または「改行をそのまま改行にする」をオン）
💡ヒント・注意点
  • 書いたものはブラウザの中だけで扱います。どこにも送信しません。途中のものは、この端末のブラウザに覚えておきます（別の端末やブラウザには出ません）。
  • 箇条書きの行で Enter を押すと、次の行にも記号が付きます。何も書かずにもう一度 Enter で、箇条書きを終わります。Tab / Shift+Tab で1段下げる・上げる。
  • ショートカット：Ctrl+B 太字、Ctrl+I 斜体、Ctrl+K リンク、Ctrl+S .md で保存。Tab でほかの場所へ移りたいときは、先に Esc を押します。
  • 見た目の欄で書きかえたかたまり（段落・見出し・リスト・表など）は、このツールの書き方にそろいます（例：__太字__ → **太字**、* 項目 → - 項目）。触っていないところは、そのまま残ります。<details> のような HTML のかたまりがあるときは、見た目の欄では書けません。
  • 見た目の欄では、チェックボックスを押すと [x] / [ ] が切り替わります。リンクは Ctrl を押しながらクリックで開きます。
  • リンクの URL を選んだまま URL を貼り付けると、[文字](URL) のリンクになります。
  • 画像はファイルを貼り付けられません。ネットに置いた画像の URL を ![説明](URL) で書いてください。
  • Markdown はサービスによって少しずつ違います。ここでの見た目は GitHub と同じ書き方（GFM）です。note・Qiita・Zenn・Discord などでは、出方が少し違うことがあります。
