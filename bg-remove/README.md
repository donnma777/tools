# 背景透過ツール

画像の背景を透明にするツールです（`index.html` 1ページで完結・外部の部品なし）。

## できること

- **色で抜く**：背景の色をクリックすると、似た色を透明にします。抜き方は2通り。
  - クリックしたところとつながった部分だけ（塗りつぶしのように広げる。キャラの中の同じ色は残る）
  - 画像全体の同じような色
- **囲んで切り抜く**：残したいものを四角か手書きで囲むと、背景を消します（AI なし。GrabCut のやり方で、色の分布とグラフカットで分ける）。
  - 長い辺 720px に縮めて分け、ふちは元の大きさで色を見て整える
  - ブラシでなぞってから「なぞったところを手がかりにもう一度」で分け直せる
- **塗る**：クリックしたところとつながった似た色を選んだ色で塗る。透明なところをクリックすると、つながった透明なところを塗る
- **自動**：開いたとき、四隅がそろって同じような色なら自動で抜きます。
- **調整**：似た色の範囲・ふちのなめらかさ（範囲の外側を半透明にする幅）・ふちを削る（透明なところを 1px ずつ広げる）・ふちの色のにじみを減らす（半透明のところから抜いた色の分を引く）
- **手直し**：消す・戻すのブラシ、拡大縮小（Ctrl+ホイールも）、戻す・やり直す（抜いた色とブラシの操作を並べておき、作り直す）
- **保存**：PNG / WebP（余白を切る を選べる）。「保存する画像の背景を塗る」で透明なところを色で埋めて保存（このときは JPG も選べる）

画像はサーバーに送らず、長い辺 4096px までに縮めて開きます。
