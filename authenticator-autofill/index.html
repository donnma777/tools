Chrome 拡張機能

Authenticator Autofill

2段階認証のコード・パスワード・住所・カード・メモを、パソコンの中だけで暗号化して管理する Chrome 拡張機能です。スマホを出さずに、今開いているサイトのコードをすぐコピーできます。

ダウンロード（GitHub Releases） GitHub

無料・通信なし・Chrome 102 以降（パソコン）・v0.1.0

こんな人に

  • ログインのたびにスマホを出して、Google 認証システムのコードを打ち込むのが面倒
  • パスワードや2段階認証の鍵を、クラウドに預けずに自分のパソコンだけで持っておきたい
  • Chrome に保存したパスワードを、サービス名やグループで整理したい
  • Bitwarden の無料プランで、2段階認証のコードが表示できなくて困っている（コードはこちらで出せます）
  • 住所や電話番号を、申し込みフォームにすぐ入れたい

できること

2段階認証のコード

30秒ごとに変わるコードを表示。押すだけでコピーでき、選んでいる入力欄に入れることもできます。

ログイン情報

サービス名・ID・パスワード・メモ・サイトを保存。「ID」「パス」ボタンでコピーします。

今のサイトを上に

開いているサイトのログインとコードが、一覧のいちばん上にまとまって出ます。

個人情報

氏名・郵便番号・住所・電話番号を、1項目ずつコピー・入力できます。住所をまとめてコピーも。

カード・メモ

カード番号やセキュリティコードは画面に出さず、コピーするときだけ取り出します。

カスタムフィールド

Bitwarden と同じく「テキスト・隠す・はい/いいえ」の欄を自由に足せます。

取り込み・書き出し

Google 認証システム・Chrome・Bitwarden から取り込み。Bitwarden・Chrome 向けに書き出しも。

通信なし

データはパソコンの中だけ。拡張機能そのものは通信をしません。件数の上限もありません。

インストール

Chrome ウェブストアではなく、ファイルを読み込んで使います。ビルドなどの作業は要りません。

  1. Releases から authenticator-autofill-v〇.〇.〇.zip をダウンロードして展開します。
  2. Chrome で chrome://extensions を開き、右上の「デベロッパー モード」をオンにします。
  3. 「パッケージ化されていない拡張機能を読み込む」を押し、展開してできた authenticator-autofill フォルダを選びます。
  4. ツールバーのアイコンを押して、復旧用パスワード（8文字以上）を決めます。

新しい版に入れ替えるときは、フォルダの場所を変えないでください。場所を変えると別の拡張機能として扱われ、保存したデータが見えなくなります。同じフォルダの中身を上書きしてから、chrome://extensions で再読み込みしてください。

使い方

ポップアップ

  • 開くとすぐ検索欄に入力できます。サービス名・ID・グループで絞り込めます。
  • 認証コードは押すとコピー。ログインは「ID」「パス」でコピー。サイトを新しいタブで開くボタンもあります。
  • 名前を押すと詳しい画面が開き、「編集」でその場で書き換えられます。
  • キーボードだけでも使えます（↑↓で選ぶ・Enter でコピー・Shift+Enter で ID・Ctrl+Enter でサイトを開く）。

保管庫を管理（管理画面）

  • ログイン・パスキー・認証コード・個人情報・カード・メモの追加・編集・削除
  • 認証コードとログインの紐づけ。おすすめから選べて、「おすすめでまとめて紐づける」もあります。
  • ロック解除を維持する時間（毎回入力・5分〜1時間）、保管庫を開くパスキーの登録

取り込み・書き出し

書き出し元やり方入るもの
Google 認証システムアプリの「アカウントを移行」の QR コードを画像で保存して読み込む2段階認証のコード
ほかの認証アプリotpauth:// のテキストを貼る・セットアップキーを手で入れる2段階認証のコード
Chrome・Edge・Firefoxパスワードを CSV で書き出して読み込むログイン
Bitwarden「保管庫をエクスポート」の .json（暗号化しない形式）か .csvログイン・2段階認証の鍵・カード・ID 情報・セキュアメモ・フォルダ

取り込む前に確認の一覧が出ます。すでに登録してあるものは「飛ばす・上書き・両方残す」から選べます。書き出しは、暗号化バックアップのほか、Bitwarden 形式の JSON・Chrome 形式の CSV・otpauth:// の一覧に対応しています。

書き出したファイル（Chrome や Bitwarden の CSV など）にはパスワードがそのまま書かれています。取り込んだら削除してください。

安全性

  • 保管庫は AES-256-GCM で暗号化し、鍵は復旧用パスワード（PBKDF2-SHA-256、60万回）とパスキー（WebAuthn PRF）で守っています。
  • 復旧用パスワードは保存しません。データはパソコンの中（chrome.storage.local）に暗号文として置くだけです。
  • パスワードやコードを、ページに勝手に入れることはありません。入れるのは「入力」を押したときだけで、フォームの送信もしません。
  • サイトのアイコンは Chrome がすでに持っているものを使うので、表示のための通信もしません。

暗号化しても、乗っ取られたパソコンや悪意のある拡張機能からは守れません。復旧用パスワードは長めにして、ほかで使い回さないでください。

よくある質問

無料で使えますか？

はい、無料です。広告や登録もありません。

スマホでも使えますか？

いいえ、パソコンの Chrome 用です。スマホの2段階認証アプリはそのまま使い、パソコンではこの拡張機能、という使い分けができます。

データはどこに保存されますか？

パソコンの Chrome の中だけです。暗号化した状態で保存し、どこにも送りません。別のパソコンで使うときは、暗号化バックアップを書き出して読み込みます。

復旧用パスワードを忘れたらどうなりますか？

中身を取り出す方法はありません。保管庫を開くパスキーを登録していれば、パスキーで開けます。パスワードは安全な場所に控えておいてください。

Google 認証システムから移すには？

スマホの Google 認証システムのメニューから「アカウントを移行」を選び、エクスポートすると QR コードが出ます。その QR コードを画像にして（スクリーンショットが撮れないときは、別のカメラで撮ります）、管理画面の「移行用QR画像を選択」で読み込みます。

Bitwarden と一緒に使えますか？

使えます。Bitwarden から書き出した JSON を取り込むと、2段階認証の鍵が認証コードになり、ログインに自動で紐づきます。パスワードは Bitwarden、コードはこの拡張機能、という使い方もできます。

Chrome ウェブストアにはありますか？

今はありません。GitHub の Releases から zip をダウンロードして、Chrome に読み込んで使います。

動作環境

  • Google Chrome 102 以降（Windows・Mac などのパソコン）
  • 保管庫を開くパスキーを使うときは、WebAuthn PRF に対応したブラウザーと認証器
