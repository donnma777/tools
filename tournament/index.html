トーナメント表メーカー

参加者を入れるだけで、トーナメント表ができます。試合をクリックして勝敗を入れると、配信（OBS）や会場のモニターの表示もその場で更新されます。

試合の結果

🏆 トーナメント表
💬 今の試合（テロップ）
👑 優勝者の発表
🛠 操作パネル（OBSのカスタムブラウザドック用）

上の3つは、OBSの「ソース ＋ → ブラウザ」に貼り付けます（幅1920・高さ1080）。「操作パネル」は、OBSのメニュー「ドック → カスタムブラウザドック」に貼り付けると、OBSの中で結果を入れられるようになり、そのまま配信画面に反映されます。くわしくは下の「使い方」へ。

画像・会場で使う
🖼 画像で保存（1920×1080 の PNG）
🖥 会場のモニター・プロジェクター

別ウィンドウをモニターやプロジェクターの画面に移して、F11 で全画面にしてください。ここで結果を入れると、そのウィンドウもその場で更新されます。背景は「🎨 色」の「画面の背景」で、色・グラデーション・画像にすると見やすくなります。

大会の保存

今の大会はこのブラウザに自動で保存されます。「＋ 保存」で名前を付けて取っておけます。

OBS接続（Chromeから操作するとき）

OBSの「ツール → WebSocketサーバー設定」で「WebSocketサーバーを有効にする」をオンにし、「接続情報を表示」のポートとパスワードを入れてください。同じPCのChromeで操作した結果が、OBSのブラウザソースに送られます。ドックで操作するときは不要です。

● 未接続

🎥 OBSでの使い方（おすすめ：OBSだけで完結）

  1. 左の「参加者」に、名前を1行に1人（1チーム）ずつ入れます。上から順にシード1位、2位…になります。
  2. 右の「OBSに入れる」で トーナメント表 の「URLをコピー」を押し、OBSで ソース ＋ → ブラウザ を追加してURLに貼り付けます（幅 1920・高さ 1080）。
  3. 同じく 操作パネル（OBSのカスタムブラウザドック用） の「URLをコピー」を押し、OBSのメニュー ドック → カスタムブラウザドック を開いて、ドック名（例: トーナメント操作）とURLを入れて「適用」します。OBSの中に操作パネルが出ます。
  4. 大会が始まったら、ドックのプレビューで試合をクリックして、スコアや勝者を入れます。配信画面のトーナメント表がその場で更新されます。
  5. 「今の試合（テロップ）」や「優勝者の発表」も、同じようにブラウザソースで追加して、シーンごとに出し分けられます。

🖥 Chromeで操作するとき

  1. OBSの「ツール → WebSocketサーバー設定」で「WebSocketサーバーを有効にする」をオンにします。
  2. OBSのブラウザソースには、上と同じように表示用のURLを入れておきます。
  3. 同じPCのChromeでこのページを開き、右の「OBS接続」にポートとパスワードを入れて「接続」を押します。
  4. このページで入れた結果が、OBSの画面にすぐ反映されます。

💡 ヒント・注意点

  • チーム戦は「チーム名: メンバー1, メンバー2」のように書くと、テロップや優勝者の発表にメンバーも出ます。
  • 人数が 4・8・16・32… ぴったりでないときは、上位シードから順に不戦勝（BYE）が入ります。
  • 「何本勝負」を 3 や 5 にすると、スコアが先取数に届いた時点で自動で勝者が決まります（オフにもできます）。
  • 音ゲーなど点数で競う大会は、「大会の設定」の「スコアの種類」を「点数」にします。点数を直接入力して「点数で勝敗を決める」（または Enter）で、高いほうが勝ちになります。「1試合の曲数」を2曲以上にすると、曲ごとに曲名と点数を入れて、合計点か曲ごとの勝ち数（同数なら合計点）で勝敗を決められます（「勝敗の決め方」で選びます）。テロップにも曲ごとの点数が出ます。「課題曲の候補」に曲名を入れておくと、曲名の入力欄で選べます。
  • ハンデキャップは、左の「⚖️ ハンデキャップ」で参加者ごとに数字を入れます。点数の大会では合計点に加算（マイナスも可）、本数の大会では最初から持っている本数になります。表とテロップに「HC +50,000」のように出ます（「レイアウト」で消せます）。
  • 参加者は「📋 一覧で編集」なら1人（1チーム）ずつの欄で、名前・メンバーを書いて ↑↓ で並べ替え、✕ で削除できます。「＋ 参加者を追加」「＋ チームを追加」で1つずつ、「8 人 分まとめて追加」で一度にたくさん作れます。「📝 テキストでまとめて入力」なら1行に1人（「チーム名: メンバー1, メンバー2」）でまとめて貼り付けられます。どちらで直しても同じです。
  • 対戦相手を入れ替えたいときは、「👥 参加者」の順番を入れ替えます（一覧なら ↑↓）。組み合わせを「上から順に2人ずつ」にすると、1・2行目、3・4行目…がそのまま1回戦の対戦になるので、思いどおりに組めます（シード順のときは 1位 vs 最下位…の決まった並び）。行を動かしても、入っている結果・ハンデ・棄権はその人についていきます（対戦相手が変わった試合の結果は使われなくなります）。
  • 敗者復活（シングルエリミネーション）は「🏆 大会の設定」の「敗者復活」で選びます。敗者復活トーナメントは1回戦の敗者どうしでトーナメントをして、勝ち残った人が本戦に戻ります（表の下に出ます）。ラッキールーザーは1回戦の敗者からスコアが高い人が戻ります（候補の一覧で選び直したり、🎲 で抽選したりもできます）。戻る場所は「1回戦の空き枠」か「○回戦から」を選べます。どちらも1回戦が全部終わってから決まります。
  • 代理出場は、結果を入れる欄の「代理出場」にその試合だけの代理の名前を入れます。表では代理の名前に「代理」の印が付き、テロップには「○○の代理」と出ます。参加者欄は変えないので、元の人の記録はそのままです。団体戦では、先鋒・中堅…ごとの選手を、登録メンバーから選ぶ／「✏️ 自由に入力」／「いない（不戦敗）」から選べます。「出場メンバー（この試合）」のチェックを外すとその試合に出ない人に、「＋ 追加で出る人」に書くと助っ人が加わります（人数が「自動」なら、その試合の人数も変わります）。4人登録して毎試合3人出る、のようなときは「1チームの人数」を3人にして、試合ごとに出る人を選んでください。表とテロップには「交代」の印が付きます。印は、その試合の欄の「代理の印」「交代の印」のチェックで試合ごとに外せます（全部まとめて消すときは「レイアウト」の「代理・交代の印を表示」）。
  • 形式は「🏆 大会の設定」で選べます。ダブルエリミネーションは、上が勝者側・下が敗者側・右がグランドファイナルの表になります（左右対称のレイアウトは使えません）。グランドファイナルで敗者側から来た人が勝つと、もう1試合（リセット）が自動で出ます。総当たりは星取表（○●）と、勝ち・負け・得失点（点数なら合計点）・順位の表になります。順位は勝ち数 → 得失点差（点数なら合計点）の順で決めます。表のマスをクリックすると、その試合の結果を入れられます。
  • スイスドローは、毎ラウンド同じくらいの成績の人どうしで当たります（同じ相手とは当たりません）。次のラウンドの組み合わせは、前のラウンドの試合が全部終わると自動で決まります。順位は勝ち数 → Bh（ブッフホルツ：当たった相手の勝ち数の合計。強い相手と当たった人ほど上）→ 得失点差の順です。人数が奇数なら、毎ラウンド1人が不戦勝（1勝）になります。
  • 曲ごとに弾く人が変わる（団体戦にしない点数・複数曲の大会）ときは、結果の欄の「○曲目の選手」で、登録メンバーから選ぶか自由に入力できます。メンバーを書いたチームがあれば自動で出ます（「大会の設定」の「曲ごとに出た選手を入れる」でも出せます）。テロップには曲ごとの点数の横に名前が出ます。
  • 勝ち抜き戦は、団体戦をオンにして「団体戦の方式」で選びます。勝った人が残り、負けた側は次の人に交代して、相手チームを全員倒したら勝ちです（引き分けは両方とも交代）。表の数字は残り人数です。本数なら対戦ごとに「勝ち」「引き分け」を押し、点数なら点数を入れて Enter で次の対戦へ進みます。
  • 団体戦は「🏆 大会の設定」で「団体戦」をオンにします。参加者は「チーム名: 先鋒, 中堅, 大将」のように1行に1チーム書くと、対戦の選手名に順番どおり入ります（試合ごとに書き換えもできます）。トーナメント表や順位表でも、チーム名の下にメンバーが小さく出ます（「レイアウト」の「チームのメンバーを表示」で消せます）。本数なら対戦ごとに「勝ち」を押し、過半数を取ったチームが自動で勝ちます（同数なら「チームの勝ち」で決めます）。点数なら対戦ごとに点数を入れ、合計点か勝った人数で決めます。
  • 🎲 抽選（「👥 参加者」）を押すと、参加者をシャッフルして、配信画面のトーナメント表で「名前がシャッフルされて、シード順に1人ずつ枠に入る」演出が流れます。入っている試合の結果は消えます。1人あたりの時間は「レイアウト」で変えられます。演出を流したくないときは「🔀 シャッフル」を使ってください。
  • 失格・棄権は、試合の結果の欄の「失格」「棄権」で相手の勝ちにできます（もう一度押すと取り消し）。大会の途中で抜けた人は、左の「🚫 棄権・失格した参加者」で選ぶと、まだ結果のない試合がまとめて相手の不戦勝になります。
  • 試合を「🔴 配信中にする」と、トーナメント表でその試合が光り、テロップにも LIVE と出ます。
  • 名前の書き間違いは、途中で直しても結果は消えません。行を並べ替えたり、人数を変えたりすると、組み合わせが変わった試合の結果は使われなくなります。
  • 画像で保存：右の「画像・会場で使う」で、トーナメント表・今の試合・優勝者を 1920×1080 の PNG で保存できます。X などに投稿するときは「背景を塗る」をオンに。
  • 会場のモニター・プロジェクター：「別ウィンドウで表示」で開いたウィンドウを会場の画面に移し、F11 で全画面にします。ここで結果を入れると、そのまま更新されます。
  • 保存はこのブラウザの中です。別のPCへは「ファイルに書き出す」で持っていけます。
