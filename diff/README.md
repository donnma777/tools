# テキスト比較（diff）

2つの文章の違いを、行と文字で色分けして見せるツールです。比べるのはブラウザの中だけで、文章はどこにも送りません。

| ファイル | 内容 |
|----------|------|
| `index.html` | 画面と処理（1ファイル。外のライブラリは使わない） |

## できること

- **入れ方**：貼る・ファイルを開く・ドロップ（2つ一緒に落とすと前と後に入る）。UTF-8 で読めなければ Shift_JIS。5MB まで
- **出し方**：並べて（左右）／まとめて（1列、- と +）。同じ行が続くところは前後3行を残してたたみ、押すと開く。「同じ行も全部出す」
- **文字の違い**：続けて消えた行と増えた行を組にして「変わった行」にし、その中を1文字ずつ比べて、変わった文字だけ濃く出す。変わったところにはさまれた2文字までの「同じ」は変わったところに入れる（日本語が細切れにならないように）。ほとんど全部ちがう行は色分けしない
- **単語ごと**：「行の中の違い」を「単語ごと」にすると、単語で区切って比べる。日本語は `Intl.Segmenter('ja', { granularity: 'word' })`、使えないブラウザは文字の種類（漢字・ひらがな・カタカナ・英数字）のまとまりで区切る。はさまれた空白・記号だけの「同じ」は、変わったところに入れる
- **無視**：空白の違い（前後の空白を除き、続く空白・全角の空白を1つに）／大文字・小文字／全角・半角（NFKC）／空の行（比べる前に除き、行番号は元のまま）。出す文字は元のまま
- **次の違い・前の違い**（F7・Shift+F7）、入れかえ、差分をコピー（unified diff の形。前後3行、6行以内の間はつなぐ）
- 文章と設定は localStorage（`donnma-diff`、それぞれ 30 万文字まで）に覚える

## 開発メモ

- 差分は Myers の O(ND)（前と後ろの同じところを先に除く）。違いが 6000 を超えたら、残りは全部「消えた・増えた」にする。
- 行の中の文字の違いも同じ関数を使う（長さの積が 400 万を超える行は色分けしない）。
