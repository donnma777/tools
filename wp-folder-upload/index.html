WordPress プラグイン

Folder Upload

WordPress の wp-content/uploads の中の 好きなフォルダへ、ファイルやフォルダごとアップロードできるプラグインです。標準の「年/月」フォルダとは別に、決まった場所にファイルを置きたいときに使います。

ダウンロード（GitHub Releases） GitHub

無料・WordPress 6.0 以上・PHP 8.0 以上・GPLv2 or later

できること

好きなフォルダへ置く

uploads の中のフォルダを選んでファイルを置けます。フォルダをドラッグすると、中の構成ごと置けます。

メディアライブラリにも登録

置いたファイルを、メディアライブラリにも登録するか選べます。

同じ名前のとき

「別の名前で置く」か「上書きする」かを選べます。

名前を変える

ファイル名を変えると、サイズ違いのファイルと記事の本文の URL もまとめて書き換えます。メディアの詳細画面からも変えられます。

管理画面の「メディア」→「フォルダにアップロード」から使います。

安全のために

  • 使えるのは管理者だけです。送信のたびに nonce も確かめます。
  • 置き場所は uploads の中だけです。.. やシンボリックリンクで外に出られないよう、実際のパスでも確かめます。
  • 置けるのは画像・PDF・動画・音声・フォント・CSS・SVG の決まった拡張子だけです。中身（MIME・画像として読めるか）も確かめます。
  • PHP のコードが入ったファイルは置けません。SVG は script や外部の読み込みなど、危ないものが1つでもあれば断ります。

インストール

  1. Releases から zip をダウンロードします。
  2. WordPress の管理画面で「プラグイン」→「新規追加」→「プラグインのアップロード」を開き、ダウンロードした zip を選んで「今すぐインストール」を押します。
  3. プラグインを有効化すると、「メディア」の中に「フォルダにアップロード」が出ます。

よくある質問

無料で使えますか？

はい、無料です（GPLv2 or later）。

「上書きする」を選ぶと元のファイルはどうなりますか？

置き換わって、元には戻せません。心配なときは「別の名前で置く」を選んでください。

WebP Upload と一緒に使えますか？

使えます。Folder Upload で置いたファイルは、置いたままの形で使うため WebP に変換されません。

編集者や投稿者も使えますか？

いいえ、管理者だけです。

動作環境・注意

  • WordPress 6.0 以上、PHP 8.0 以上（fileinfo 拡張が必要）
  • 管理画面は日本語だけです
  • 個人で作ったものです。サポートや不具合の対応はお約束できません

ライセンス

GPLv2 or later です。
