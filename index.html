配信の便利ツールFor Streamers

OBS Studio オーバーレイOBS用PC向け
配信オーバーレイテーマ
配信向け
サイバーパンク、ゲーミング、和風などOBS用オーバーレイテーマを公開中。テーマ一覧・使い方は専用ページで確認できます。
オーバーレイ一覧を見る → 解説ページ
YouTube / Twitch チャットOBS用PC向け
チャットCSSジェネレーター
配信向け
YouTubeライブ・Twitchのチャット欄をOBSでおしゃれに表示。プレビューを見ながらフォント・縁取り・吹き出し・スパチャ/Bits・アニメーションを設定できます。
ジェネレーターを開く →
YouTube 登録者数OBS用PC向け
登録者数カウンター・目標ゲージ
配信向け
YouTubeの登録者数を自動で取得して、OBSでおしゃれに表示。「目標まであと○人」の目標ゲージも出せます。グラデーション・縁取り・見出しや単位・背景の箱を、プレビューを見ながら設定できます。
ツールを開く →
時計・配信時間OBS用PC向け
時計・経過時間
配信向け
OBS のブラウザソースで使える時計です。配信・録画を始めてからの時間を自動で数え、海外の時刻も並べられます。見た目は配信オーバーレイと同じ 8 つから。選んで URL をコピーするだけです。

だれでも使えるツールWeb Tools

大会・配信・会場OBS対応
トーナメント表メーカー
大会・イベント
参加者を入れるだけで、トーナメント・ダブルエリミネーション・総当たり・スイスドローの表を自動で作成。点数（音ゲーのスコア）や団体戦、敗者復活、課題曲のピック・BAN・ルーレットにも対応。配信（OBS）・会場のモニター・画像保存で使えます。

抽選・罰ゲーム・順番決めOBS対応
ルーレット
抽選・ゲーム
項目・当たりやすさ・色を自由に決めて回せるルーレット。ブラウザでそのまま使えて、OBSの配信画面にも出せます（ドック・Chromeから操作、透過背景・履歴表示・効果音つき）。罰ゲーム・順番決め・抽選に。
ツールを開く →
順番決め・チーム分け・罰ゲームOBS対応
あみだくじ
抽選・ゲーム
参加者と結果を入れるだけで作れるあみだくじ。横線を足してから始めたり、結果を隠して1人ずつ・全員まとめて開けたりできます。ブラウザでそのまま使えて、OBSの配信画面にも出せます（画像保存・効果音つき）。
ツールを開く →
ブログ・YouTube・SNSスマホOK
サムネイルメーカー
画像づくり
ブログのアイキャッチ、YouTubeのサムネイル、SNSの共有画像をブラウザだけで作れます。文字を入れて、背景の柄と画像を選ぶだけ。長い文字は自動で収まります。画像はどこにも送信しません。
ツールを開く →
イラスト・写真・商品画像スマホOK
背景透過ツール
画像づくり
背景の色をクリックするだけで、似た色をまとめて透明にします。消しゴム・復元ブラシで仕上げて、PNG・WebP で保存。単色の背景やグリーンバックに。画像はどこにも送信しません。
ツールを開く →
URL・Wi-Fi・連絡先スマホOK
QRコードメーカー
画像づくり
URL・Wi-Fi・連絡先・メールなどのQRコードを、期限なし・登録なしで作れます。ドットや角の形、色・グラデーション、まん中のロゴを変えて、PNG・SVG・JPG で保存。画像からの読み取りもできます。入れた内容はどこにも送信しません。
ツールを開く →
名前・SNS・QRコードスマホOK
名刺メーカー
画像づくり
名前・SNS・QRコードを入れるだけで名刺を作れます。配信者のイベントや交流会に。4つのレイアウト、色・フォント・写真を選んで、家で印刷できる A4・10面の PDF や、印刷所に出せる PDF・PNG で保存。画像はどこにも送信しません。
ツールを開く →
立ち絵のパーツ分け・差分スマホOK
PSD レイヤー書き出し
画像づくり
PSD をブラウザで開いて、レイヤーを選んで PNG で保存できます。表示を切り替えた見た目を1枚で、レイヤーやフォルダを1枚ずつ、全部まとめて ZIP でも。Photoshop がなくても使えて、ファイルはどこにも送信しません。
ツールを開く →
JPEG・PNG・WebPスマホOK
画像の圧縮・変換
画像づくり
画像を軽くしたり、JPEG・PNG・WebP に変換したりできます。何枚でもまとめて変換、画質・大きさ・「○KB 以下」を選べて、変換前と見比べられます。撮影場所の情報も消えます。画像はどこにも送信しません。
ツールを開く →
X・Discord・LINE・FacebookスマホOK
OGPチェッカー
サイトづくり
URL を入れるだけで、OGP の画像やページの情報を調べられます。X・LINE・Discord など、いろいろなサービスに貼ったときの見え方も確かめられて、問題があれば直し方も案内します。
ツールを開く →
Google・AI・X・AdSenseスマホOK
robots.txt チェッカー
サイトづくり
URL を入れるだけで、Google・AI（ChatGPT・Claude など）・X・AdSense などのクローラーがそのページを読めるかを調べます。どの行で止められているか、noindex やサイトマップも確かめられ、robots.txt を書き換えて公開前に試せます。
