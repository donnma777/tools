# 履歴書メーカー

入力するだけで履歴書・職務経歴書・スキルシートを作るツールです。履歴書の様式は5つから選べます。入れた内容も写真も PDF づくりもブラウザの中だけで、どこにも送りません。

| ファイル | 内容 |
|----------|------|
| `index.html` | 画面・描画・PDF 作り（1ファイル） |
| `../common/ask.js` | 読み込み・すべて消すときの確認 |

## 様式

1枚目の上（氏名・生年月日・写真・現住所・連絡先）はどれも同じです。

| 様式 | 学歴・職歴 | 免許・資格 | 2枚目のおもな欄 |
|------|-----------|-----------|----------------|
| 厚生労働省様式（2021） | 1枚目 19行＋2枚目 | 2枚目（続きとあわせて 12行） | 志望の動機・特技など、本人希望 |
| 転職用 | 1枚目 21行＋2枚目（1行 7.5mm） | 2枚目（続きとあわせて 13行） | 職務の要約、自己PR、志望の動機、本人希望 |
| アルバイト・パート用 | 1枚目 12行 | 1枚目 5行 | 志望の動機、希望の曜日・時間帯、通勤時間・扶養家族数・配偶者・配偶者の扶養義務、趣味・特技、本人希望 |
| 学生用 | 1枚目 12行 | 1枚目 5行 | 学生時代に力を入れたこと、自己PR、得意な科目・研究テーマ／趣味・特技、志望の動機、本人希望 |
| JIS 風（旧様式） | 1枚目 19行＋2枚目 | 2枚目（続きとあわせて 12行） | 志望の動機・特技など（右に通勤時間・扶養家族数・配偶者・扶養義務）、本人希望 |

入力はどの様式でも共通です（様式を切り替えても消えません）。使わない欄は、入力の画面で隠します。

## 職務経歴書

左上の切り替えで履歴書と職務経歴書を行き来します。氏名・記入日・職歴・免許・資格は共通（`data-doc` で欄を出し分け）。

| 項目 | 内容 |
|------|------|
| 中身 | 職務要約、職務経歴（会社ごとに期間・事業内容・資本金・売上高・従業員数・雇用形態・配属先・常駐先（`assign`）・部署・期間ごとの業務（`terms`：異動・配属先の変更ごとに期間＋配属先＋部署＋業務。終わりが空なら次の期間の始めまで）・業務内容・実績）、活かせる経験・知識・スキル、資格（履歴書の免許・資格）、自己PR、「以上」 |
| ページ | A4。中身に合わせて増える（`cvLayout()` が書く場所を先に決めてページを分け、`drawCvPageTo()` で描く）。見出しは次の行と離さない。「以上」だけで次のページにしない |
| 会社を作る | 「履歴書の職歴から作る」：「〇〇 入社」の行で会社を始め、「退職」で終わり、配属・異動・登用は部署・役職に、ほかは業務内容に入れる（`companiesFromJob()`） |
| 期間 | 「2021/4」「2021年4月」「R3/4」を読む（`parseYM()`）。終わりが空なら「現在」 |
| 職歴から作るときの期間 | 年月つきの「〇〇に配属／異動／常駐」の行で期間を分ける（〇〇は配属先）。入社と同じ月なら、会社の配属先にする |
| 履歴書とのずれ | 会社は履歴書と別に持つ（いつも連動はしない）。履歴書の職歴の会社（`companiesFromJob()`）と職務経歴書の会社を古い順に1社ずつ比べ、会社名・入社・退職が違えば帯で知らせる（`companyDiffs()`）。「職務経歴書を履歴書に合わせる」は会社名と期間だけ直し、業務内容などは残す。「履歴書を職務経歴書に合わせる」は「入社」「退職」の行の会社名・年月を直す（退職の行を足す・消す、「現在に至る」も合わせる。会社の数が同じときだけ）。どちらも「元に戻す」あり |
| 保存 | PDF：A4（ページ数は中身に合わせて）。A3 はなし |

## スキルシート

エンジニア向け（SES・フリーランス・IT 転職）。A4 縦（最初）か A4 横を選ぶ（`ssOrient`）。縦は案件の表の列を細くする。氏名・ふりがな・生年月日・性別・資格は共通。自己PR はスキルシート用（`ssPr`）を職務経歴書（`cvPr`）と別に持つ（前の版のデータは `migrate()` で `cvPr` を写す。「職務経歴書の自己PRを写す」ボタンあり）。

| 項目 | 内容 |
|------|------|
| 基本情報 | 氏名（イニシャル／氏名。イニシャルはふりがなの頭文字から 名.姓 の順で作る＝`autoInitials()`、書きかえも可）・年齢・性別・最寄り駅・稼働開始・経験年数（空ならいちばん古い案件から） |
| スキル | 種類（言語・フレームワーク・DB・OS・クラウド・ツール・その他）・名前・年数・レベル（◎○△）。種類ごとに1行にまとめて描く |
| 案件の経歴 | 期間（と長さ）・案件名・業種・概要・担当した業務・役割・人数・使用技術・担当工程。担当工程は「自由に書く」（最初。文で書き、よく使う工程はボタンで足す。空なら ● の工程から「詳細設計〜テスト」のように作る＝`phaseFromTable()`）か「● の表」（要件定義〜運用保守の6列）を選ぶ（`ssPhaseMode`）。表の見出しはページごとにくり返す。見出しだけがページの下に残らないようにする。使用技術は「 / 」の区切りで折り返す |
| 作る | 「職務経歴書の会社から作る」：会社1つを案件1つにする（会社の中で分けるのは手で） |
| 最終学歴・所属会社 | 最終学歴（`ssEdu`。空なら履歴書の学歴のいちばん下の卒業・修了の行から作る）は基本情報の枠の下に1行。案件の所属会社（`company`）は案件名の下に「所属：〇〇」（案件名と同じなら出さない）。「職務経歴書の会社から作る」は、期間を分けた会社なら期間ごとに案件を作る |
| 表示する項目と名前 | 見出し・基本情報の6つの枠・欄（得意分野〜案件の経歴）・スキルの年数とレベル（`skYears`・`skLevel`。レベルを出さなければ ◎○△ の説明も出さない）・案件の表の列を、出す／出さない（`ssOff`、`,` 区切り）と名前の書きかえ（`ssLabels`）。消した枠の幅は残りで分け、消した列の幅は「案件名・概要」の列に足す。見出しと案件の内容の列は消せない。前の `ssShowAge: false` は `ssOff` の `age` に引き継ぐ |
| PDF | A4 縦（210×297mm）か A4 横（297×210mm）。イニシャル表示のときはファイル名にも氏名を入れない |
| AI | 得意分野・スキル一覧・案件の経歴・自己PR を頼む（`buildSsPrompt()`）。技術や工程は配列で返ってきても読む。工程は決まった名前だけを決まった順に |

## できること

| 項目 | 内容 |
|------|------|
| 学歴・職歴 | 1行ずつ足して並べ替え。「学歴」「職歴」の見出し、職歴がないときの「なし」、「現在に至る」（任意）、「以上」は自動 |
| 表示する項目と名前 | 3つの書類とも、項目を出す／出さないと名前を選べる（履歴書 `rsOff`・`rsLabels`、職務経歴書 `cvOff`・`cvLabels`、スキルシート `ssOff`・`ssLabels`。項目の一覧は `DOCS`）。履歴書は1枚目（記入日・写真・ふりがな・生年月日・性別・現住所・連絡先・免許資格）と2枚目の欄（様式ごと）を消せて、消した分は `rsLayout()` が詰める：1枚目は学歴・職歴の行を増やし、2枚目は文の欄が元の高さの比で分け合う（通勤時間などの小さい枠の段はそのまま）。何も消さなければ元の様式と同じ。消した欄は AI にも頼まない |
| 表から取り込む | Excel・スプレッドシートの表（タブ区切り）や「2012年4月 〇〇 入学」のような行を貼ると、年・月・内容に分けて学歴・職歴・免許・資格に振り分ける（`parseHistoryText()`）。見出しの行があれば従い、なければ「入学」「入社」「合格」などの言葉で分ける。行ごとに入れる先を選び直してから、置き換えるか後ろに足す |
| 年 | 西暦・和暦を切り替え（中身は西暦で持つ）。入力は「2020」「R2」「令和2」「H30」「平成元」どれでも西暦にそろえる。入力の途中や読み込んだデータで「H24」のままでも、表示は `ymYear()`・`ymText()` で設定の形（平成24／2012）にそろえる |
| 早見表 | 生年月日から中学卒業〜大学院修了の年月（4/2〜翌4/1 生まれが同じ学年）。「＋」で学歴に足す |
| 写真 | 30×40mm に切り抜き（大きさとドラッグで位置）。入れないときは「写真をはる位置」の枠 |
| 配偶者など | 「有・無」を印刷し、選んだほうを丸で囲む。書かないこともできる |
| 見本 | 「見本を見る」で架空の人（見本 花子）の見本をプレビューにだけ出す。様式ごとに中身が違う（`SAMPLES`）。表示中は PDF を保存できず、何か入力すると閉じる（様式・年の書き方・文字の切り替えでは閉じない）。「この見本で書き始める」で入力欄に写す |
| AI で文章を整える | 応募先・メモ・学歴職歴・免許・今の下書きから、ChatGPT などに貼るプロンプトを作ってコピー。欄ごとの文字数の目安は枠の大きさから出す（`aiFields()`）。「学歴・職歴を行数に収める」は、様式で使える行数（`historyRowsMax()`）をプロンプトに入れ、`ed`・`job` の行で返してもらう。職務経歴書では職務要約・職務経歴（会社ごとの JSON）・スキル・自己PR を頼む（`buildCvPrompt()`）。答えは決まった JSON で返してもらい、貼ると欄に入る（文字列の中の本物の改行も読む・元に戻せる・AI からの質問を表示）。氏名・住所・電話・メール・生年月日は入れない |
| プレビューの拡大 | プレビューのページか「🔍 拡大」を押すと全画面で開く。幅に合わせる（最初）・全体・＋−（50〜400%。100% は実際の大きさ）・ページ送り。キーは ← → で前後のページ、+ − で拡大・縮小、0 で幅に合わせる、Esc で閉じる。Ctrl（⌘）＋ホイールでも拡大・縮小。マウスでつかんで動かせる。倍率ごとに描き直すので文字がぼやけない（キャンバスは 7000×9000px まで） |
| Excel・スプレッドシート | 今の書類（履歴書・職務経歴書・スキルシート）を、あとから書きかえられる表にする。「Excel で保存」は .xlsx（A4・幅を1ページに合わせて印刷。履歴書は写真つき・1枚目のあとで改ページ。Google スプレッドシートでもドライブに上げて開ける）。「スプレッドシート用にコピー」は HTML の表とタブ区切りの文字をコピー（写真は入らない）。表の形は `resumeSheet()`・`cvSheet()`・`ssSheet()` で作り（列の幅・行の高さは mm）、`makeXlsx()`（自前の ZIP。圧縮なし）と `sheetHtml()` で書く。Excel は折り返したセルの高さを自分で合わせないので、`fitRows()` で行数から高さを決める。スキルシートは出す項目・名前・向き・工程の書き方を守り、基本情報の枠の幅は列の区切りを足して PDF と同じ割合にする |
| 記録 | AI の答えを欄に入れると自動で、ほかは「今の文を記録する」で、欄ごとの文を応募先・メモ・様式・日時といっしょに残す（学歴・職歴と職務経歴は JSON の文字で残し、戻すときに読み直す）（localStorage `donnma-rirekisho-log`、最大 500 行）。一覧から「欄に戻す」。CSV で保存・読み込み（BOM 付き UTF-8。列は 日時・応募先・様式・出どころ・欄・欄キー・文章・メモ。= + - @ で始まる文は先頭に ' を付ける。読み込みは同じ行を重ねない） |
| 文字 | 明朝（Noto Serif JP）・ゴシック（Noto Sans JP）。長いときは小さくして、それでも入らなければ「…」と注意を出す |
| 保存 | 履歴書：PDF の A4 2枚／A3 1枚（見開き）。職務経歴書：PDF の A4 |
| 覚えておく | localStorage（`donnma-rirekisho`、写真は `donnma-rirekisho-photo`。長い辺 1000px の JPEG）。JSON の書き出し・読み込み、すべて消す |

## 開発メモ

- 描画は名刺メーカーと同じく mm で考えて `k`（px/mm）を掛けて描く（`makePainter`）。保存は 300dpi。
- 様式は `FORMS` に数字で書く（`rowH`・`hist`・`lic`・`tables`・`items`）。2枚目は `items` を上から積み、`h` のない欄が下（282mm）まで伸びる。欄の種類は `box`（文）・`split`（横に並べた文）・`cells`（小さい枠）・`side`（文の右に小さい枠）。
- 入力の画面は `data-field` の付いた欄を、今の様式で使う欄（`formKeys()`）だけ出す。見出しは `data-label` に `FORMS` の名前を入れる。
- 履歴書の置き方（1枚目の枠の位置・学歴職歴の行数、2枚目の表の行の分け方・欄の高さ）は `rsLayout()` が決める。描画・Excel・AI の字数の目安はこれを使う。
- 見本は、描くときだけ `view()` で `S` と写真を差しかえる（入力は変えない）。スキルシートの見本は別の人（エンジニア。`SAMPLE_SS`）。
- 職務経歴書とスキルシートは、書く場所を先に決めて（`cvLayout()`・`ssLayout()`）からページごとに描く。
- PDF は自前（画像を置くだけ）。A3 も 1ページずつ描いて 2枚並べる（iPhone の canvas の上限をこえないように）。
- 文字は画像なので、PDF の文字は選べない。
