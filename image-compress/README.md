# 画像の圧縮・変換

画像を軽くしたり、JPEG・PNG・WebP（作れるブラウザなら AVIF も）に変換したりするツールです。変換はブラウザの canvas だけで行い、画像はどこにも送りません。

| ファイル | 内容 |
|----------|------|
| `index.html` | 画面と変換の処理（1ファイル。外のライブラリは使わない） |

## できること

- **入れ方**：選ぶ（複数）・ドロップ・Ctrl+V の貼り付け。一度に 100 枚まで
- **形式**：WebP / JPEG / PNG / AVIF / 元のまま（GIF・BMP などは PNG）。AVIF は `canvas.toBlob('image/avif')` で作れるブラウザだけボタンを出す
- **画質**：10〜100（PNG にはない）。JPEG のときは透明なところを決めた色で塗る
- **大きさ**：長い辺を決めた大きさ以下に縮める（大きくはしない）。半分ずつ縮めてから仕上げるので、大きく縮めてもギザギザが出にくい
- **重さの目標**：「○KB 以下」。画質を二分探し（7回）で決め、入らなければ 85%・70%… と小さくしていく
- **重くなったら元のまま**：大きさも形式も変えていないのに重くなったときは、元のファイルを使う
- **見比べ**：左が元・右が変換後で、境目をドラッグで動かす。「等倍で見る」で変換後の画素を 1:1 で見る
- **保存**：1枚ずつ、または全部を ZIP（圧縮しないで入れるだけ。名前は UTF-8。同じ名前は `-2` などを付ける）
- **よく使う設定**：Web 用（WebP・1920px・80）/ OGP 用（JPEG・1200px・1MB 以下）/ SNS 用（JPEG・4096px・5MB 以下）/ 透明なまま（WebP・90）
- 設定は localStorage（`donnma-image-compress`）に覚える

## 開発メモ

- 画像は `createImageBitmap(file, { imageOrientation: 'from-image' })` で読むので、スマホの写真の向き（EXIF）は直してから描く。canvas から書き出すので、EXIF（GPS など）は残らない。
- 設定を変えると全部を変換し直す。途中で設定が変わったら、前の変換は `gen` で捨てる。
