Contact Inbox

WordPress でお問い合わせフォームを作り、送られた内容を受信一覧で見て、管理画面からそのまま返信できるプラグインです。

無料・WordPress 6.3 以上・PHP 7.4 以上・GPLv2 or later

できること

フォームを管理画面で作る

項目の種類・必須・文字数・選択肢・並び順を、画面で決められます。フォームはいくつでも作れて、複製もできます。

ブロックで置く

ブロック「フォーム」を置いて、表示するフォームを選ぶだけ。エディタでも実際の見た目が出ます。

受信一覧で見る

送られた内容は保存され、未読・既読・返信済みが一目で分かります。検索・絞り込み・CSV 書き出しもできます。

管理画面から返信

ひな形と元の問い合わせの引用から書き始めて、そのまま送れます。返信の履歴も残ります。

メールと Discord に届く

送られるとメールで届きます。SNS Post か Discord Post Notify を入れれば Discord にも通知します。

迷惑メールに強い

見えない入力欄・送信までの秒数・回数制限でロボットを止め、Akismet があれば判定にも使います。

インストール

  1. Releases から zip をダウンロードします。
  2. WordPress の管理画面で「プラグイン」→「新規追加」→「プラグインのアップロード」を開き、ダウンロードした zip を選んで「今すぐインストール」を押します。
  3. プラグインを有効化すると、メニューに「お問い合わせ」が増え、名前・メール・本文の「お問い合わせ」フォームが1つ入ります。
  4. 「お問い合わせ」→「フォームの編集」で、項目と送信先のメールアドレスを確かめます。
  5. フォームを置きたいページに、ブロック「フォーム」を追加して、表示するフォームを選びます。

項目の種類

種類使いどころ
1行テキスト・複数行テキスト名前・件名・本文など。「くり返し」にすると、送る人が「＋ 追加」で欄を増やせます
メールアドレス・電話番号・URL形が正しいかを確かめます。メールアドレスは返信先にできます
スラッグ半角の英小文字・数字・ハイフンだけの名前（例：new-year-tea-room）
プルダウン・ラジオボタン選択肢から1つ選ぶ。件名に使うこともできます
チェックボックスいくつでも選ぶ。1つだけにすれば「同意する」の確認にも使えます

受信一覧と返信

管理画面の「お問い合わせ」→「受信一覧」に、送られた内容が新しい順に並びます。開くと既読になり、返信すると「返信済み」になります。「未返信」で絞り込めば、返信待ちの一覧になります。

1件の画面の下にある返信欄から、フォームの送信元のアドレスとして相手に送れます。宛先を確かめるダイアログが出てから送ります。

Xserver では、送った返信を送信元アドレスのメールボックスの「送信済み」にも保存します。IMAP でつないだメールソフトから、そのままやり取りを続けられます。

迷惑メール対策

  • 人には見えない入力欄と、表示から送信までの秒数で、ロボットの送信を捨てます
  • Akismet が有効なら、迷惑メールの判定に使います。判定されたものは受信一覧の「迷惑メール」に残り、30日で消えます
  • 同じ IP からは10分に5回までしか送れません
  • 1つの項目は5万文字までです

よくある質問

無料で使えますか？

はい、無料です（GPLv2 or later）。

Contact Form 7 から乗り換えられますか？

フォームは「フォームの編集」で作り直してください（項目を並べるだけです）。Contact Form 7 で送られた過去の内容は移りません。

送信者への自動返信はありますか？

ありません。送信先のメールアドレスにサーバーの自動応答を設定すると、送信者に届きます（送信者のアドレスは返信先に入ります）。

添付ファイルは受け取れますか？

受け取れません。安全のため、文字の項目だけにしています。

メールが届きません。

送られた内容は受信一覧に残っています。メールは WordPress の標準の送信（wp_mail）で送るので、届かないときは SMTP のプラグインなどでメールの送り方を整えてください。

動作環境・注意

  • WordPress 6.3 以上、PHP 7.4 以上
  • WordPress の「個人データのエクスポート／消去」に対応しています（送信者のメールアドレスで探します）
  • 管理画面は日本語だけです
  • 個人で作ったものです。サポートや不具合の対応はお約束できません

ライセンス

GPLv2 or later です。
