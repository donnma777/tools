名刺メーカー

名前・SNS・QRコードを入れるだけで名刺を作れます。配信者のイベントや交流会に。家で印刷できる A4・10面の PDF や、印刷所に出せる PDF・PNG で保存できます。画像はどこにも送信しません。

🔍使い方
  1. 左で名前・SNSなどを入れます。QRコードは、SNS の行から選ぶか、好きな URL を入れられます。
  2. デザインで向き・レイアウト・色・フォントを選び、必要なら写真や背景の画像を入れます。
  3. 右の名刺を見て、点線（安全な範囲）から文字がはみ出していないか確かめます。
  4. 保存のしかたを選んで 「⬇ 保存」。入れた内容は、このブラウザに自動で覚えておきます。
🖨️印刷のしかた
  • 家で印刷：A4・10面の名刺用紙（エーワン・コクヨなどの「マルチカード」「名刺用紙」、上下 11mm・左右 14mm の余白のもの）に合わせてあります。
  • 印刷するときは、大きさを「実際のサイズ」「100%」にしてください。「ページに合わせる」だとずれます。
  • 両面にするときは、1ページ目（表）を印刷したあと、紙を裏返して 2ページ目（裏）を印刷します。プリンターの両面印刷なら「長辺とじ」で。
  • トンボ付きは、ふつうの紙に印刷して、まわりの線に合わせてカッターで切る用です。
  • 印刷所に出すときは「塗り足し 3mm」の PDF か PNG を使ってください。まわり 3mm は切り落とされるので、背景だけがはみ出すようにしてあります。
💡ヒント・注意点
  • QRコードは、作ったあとにスマホで読めるか確かめてください。背景の画像の上でも読めるよう、白い台を付けています。
  • QRコードは中身をそのまま入れているので、期限はありません。そのかわり、あとから飛び先は変えられません。
  • 写真・画像はブラウザの中だけで使い、どこにも送信しません。大きい画像は、覚えておくときに小さくします。
  • 名前が長いときは、入るように自動で小さくなります。文字が小さすぎると印刷で読みにくいので、ひとことや SNS は少なめがおすすめです。
