# 名刺メーカー

名前・SNS・QRコードを入れて名刺を作るツールです。描くのも PDF を作るのもブラウザの中だけで、画像はどこにも送りません。

| ファイル | 内容 |
|----------|------|
| `index.html` | 画面・描画・PDF 作り（1ファイル） |
| `../qr/qr-core.js` | QRコード（QRコードメーカーと同じもの。`?v=` は qr/index.html とそろえる） |

## できること

- **大きさ**：91×55mm（日本の名刺）。横・縦
- **中身**：名前・読み/英字・肩書き・ひとこと（2行）・SNS/連絡先（5行。X・YouTube・Twitch・Instagram・TikTok・Bluesky・ニコニコ・Discord・Web・Mail・そのほか）
- **QRコード**：SNS の行（ID から URL を作る）か、好きな URL。表の右下（入れないこともできる）と、裏に大きく。読めるように白い台を付ける
- **レイアウト**：シンプル・まんなか・写真を左・上に帯（縦のときは上から積む形に変わる）
- **デザイン**：色のテーマ 8 つ＋好きな色、背景（単色・グラデーション・水玉・画像）、フォント 7 つ（Google Fonts）、名前の大きさ
- **裏**：QRを大きく・名前だけ（アクセント色）・画像・なし
- **保存**：
  - A4・10面 PDF（2列×5段・上下 11mm・左右 14mm。エーワンなどの名刺用紙）。トンボ付きも。縦の名刺は回して入れ、裏は逆向きに回す（長辺とじの両面で合うように）
  - 印刷所向け PDF（塗り足し 3mm。TrimBox・BleedBox 付き）
  - PNG（350dpi。pHYs で解像度を書き込む）、塗り足し付きも
- 入れた内容は localStorage（`donnma-meishi`、画像は `donnma-meishi-img-*`。小さくしてから保存）

## 開発メモ

- 描画は mm で考えて、`k`（px/mm）を掛けて描く（`makePainter`）。見え方は画面の幅、保存は 350dpi。
- 文字の「安全な範囲」は端から 3mm。印刷所向けは、背景だけ塗り足しまで広げる。
- PDF は自前（画像を置くだけ）。画像は `CompressionStream('deflate')` で Flate、使えないブラウザは JPEG。
- canvas で描く前に `document.fonts.load(…, 使う文字)` で、日本語フォントの必要な部分を読み込んでおく。
