# サムネイルメーカー

ブログのアイキャッチ・YouTubeのサムネイル・SNSの共有画像を、ブラウザの canvas で作って JPG / PNG / WebP で保存するツールです（`index.html` 1ページで完結）。
旧 `eyecatch/` は転送だけのページです。

## できること

- **大きさ**（`SIZES`。面積の小さい順、初期値は OGP）：400×400（アイコン）・851×315（Facebook のカバー）・1500×500（X のヘッダー）・1200×630（OGP）・1280×640（GitHub）・1280×720・1080×1080・1600×900（X の投稿）・1080×1440（Instagram 縦）・1080×1920（YouTube ショート・TikTok・ストーリー）・2560×1440（YouTube のチャンネルバナー）・2500×1686（LINE のリッチメニュー）・自由
- **背景**：水玉・ストライプ・チェック・グラデーション・無地・自分の画像・透明。背景画像は「画面いっぱい／全体が入る」と暗さを選べます。
- **切れやすい場所の目安**（`S.guideOn`）：プレビューにだけ点線を出す（`drawGuide`。`render()` で小さいプレビューに写したあとに描くので、保存する画像には写らない）。青＝まわり 5%、オレンジ＝16:9・1.91:1・2:1（縦長・正方形は 3:4）で真ん中を切り出したときに全部に残る範囲、赤＝YouTube の再生時間・縦長の上下（名前やボタン）。
- **大きさごとの目安**（`drawGuide`）：YouTube のチャンネルバナーは PC で見える帯とどの端末でも見える範囲（1546×423）、LINE のリッチメニューは6分割の区切り、X のヘッダーは左下のプロフィール画像、Facebook のカバーはスマホで見える範囲、Instagram 縦は正方形で切られる線。この5つは、16:9 などで切られる線は出さない。
- **SNS での見え方**（`#btn-sns`）：保存される画像を、X（リンクのカード・画像の投稿）・Facebook・LINE・Discord・YouTube（サムネイル・おすすめの一覧）・GitHub・YouTube ショート・TikTok（縦 9:16。右のボタンと下の説明が重なる）・Instagram（プロフィールの一覧。3:4）・プロフィール画像（丸。96・48・32px）風のカードに並べる。CSS の `object-fit: cover` と `aspect-ratio` で切り抜くだけの目安。タイトルは `S.title`、URL と説明は仮。
- **ロゴの帯の位置**（`S.bandPos`：下・上・左・右）：太さと場所は `bandOf()`。左右は縦のロゴ用で、ロゴは帯の幅に合わせる（高さは中身の 7 割まで）。中身は帯を除いた大きさで描き（`drawContent` の `fullW`・`fullH`・`dx`・`dy`）、ドラッグの量も帯を除いた大きさで割る。左右の帯の波・レースは x と y を入れ替えて `drawEdgeBumps` で描く。
- **帯のふち**（`S.bandEdge`：まっすぐ・波・レース、`bandAccent`）：ロゴの帯の中身の側のふちに、半円の波を中身へはみ出す向きに並べる（`drawEdgeBumps`）。レースは余白のレースと同じドイリー風で、穴から下が透ける。
- **まわりの余白**（`S.padOn`・`padSize`・`padColor`・`padShape`（四角・波・レース）・`padT`・`padB`・`padL`・`padR`（付ける辺）・`padRound`・`padLine`・`padAccent`）。辺ごとの幅は `padOf()`（付けない辺は 0。波・レース・点線も付けた辺だけ、角の丸みは両側の辺に余白がある角だけ）：画像の大きさはそのままで、中身を内側の大きさで描く。ふちは重なりの順の1枚（`S.order` の `@frame`。余白がオフでもいつも入っていて、一覧のカードを選ぶと、幅・色・形・角の丸み・点線の設定がカードの中に開く（`home: 'frame'`）。選択パネルのバーは余白の幅。余白のオン・オフは一覧のカードのスイッチだけ（`padOn` は `home: 'none'`）。内側の細い枠（`frameOn`）は「背景」の欄。はじめはいちばん上）。背景・光・帯（背景のすぐ上）は内側の形で切り抜き、`@frame` より上の画像や文字はふちにはみ出して描く（キャラを枠から飛び出させる）。新しく足したものは `pushLayer` で `@frame` のすぐ下に入る。帯は `draw()` の `drawBand` を、背景のすぐ上なら `underLayers`、いちばん上なら `overLayers` で描く。ドラッグの量は内側の大きさで割る。
- **横に置く画像**：自分の画像。選ばなければコードで描いたサンプル（ハート・星・うさぎ）。位置は 左・右・上・下・真ん中 と、左右・上下のずらし（プレビューでドラッグしても動く。`S.imgX`・`S.imgY` は幅・高さの %）。横長では画像と文字を横に、縦長・正方形では上下に並べます。
- **文字**：枠に収まるまで自動で小さくします。タイトルの `*〜*` で強調、そろえ方・ずらし（ドラッグ可）、文字の後ろの座布団。
- **ロゴ**（自分の画像）：「タイトルの代わり」「タイトルの上」「隅に小さく」
- **追加の文字・画像**：`S.extras`（`type` が `text` / `image`）
- **重なりの順**：`S.order`（下→上）。`@pic` メインの画像、`@text` タイトル（とロゴ）、`@sub` サブタイトル。サブタイトルは `S.subX`・`S.subY` でタイトルと別にずらせます。一覧は上ほど前。
- **設定の欄**：テンプレート → 大きさ → 画像・文字・背景 → 文字の見た目 → まとめて作る。ロゴと背景は欄ではなく、「画像・文字・背景」の一覧のいちばん下の「ロゴ」「背景」のカード（`@logo`・`@bg`。重なりの順には入らず、前へ・後ろへはない）。`SECTIONS` の「ロゴ」「背景」の項目は、作ったあとでカードの中（`logoOpts`・`bgOpts`）に移して欄を消す。スイッチをオフにすると `S.hidden` に入り、ロゴを使わない・背景なし（透明）として描く（`logoMode`・`bg` の値は残る）。
- **一覧のカードの開き方**：選んだカード（`.selected`。カードかプレビューの中身を押すと選ばれる）だけ設定を開き、ほかは見出しの行と文字を入れる欄だけ（CSS の `#extra-list > .extra-item:not(.selected)`）。足した文字・画像は選んだ状態にする。メインの画像の「置き方」（`#main-opts`）は、メインの画像のカードの中に入れる。
- **表示する・しない**（`S.hidden`：id の一覧）：一覧のどのカードにも、見出しの行にスイッチ（`hookRow` で付ける）。オフにしたものは描かず、配置も「ないもの」として計算する（メインの画像をオフにすると文字が真ん中に寄る）。余白のカードのスイッチは `S.padOn`。
- **テンプレート**：見た目を名前付きで保存（読み込んでもタイトル・サブタイトルは今のまま）
- **元に戻す**：設定の履歴。Ctrl+Z / Ctrl+Y
- **まとめて作る**：1行1枚。押したときだけ cdnjs の JSZip を読み込んで ZIP にする

## 保存場所

- 選んだ画像はサーバーに送らず、縮めてこのブラウザの localStorage に残します（入らない大きさなら、開いている間だけ使う）。
- 追加の画像は localStorage `donnma-eyecatch-extra-<id>`。
- テンプレートは画像ごと IndexedDB `donnma-eyecatch` に入れます。

## 注意

- サンプルのうさぎは どんまうんど のデザインなので、初期値にはせず選択肢のいちばん下に置き、再配布しないよう注意書きしています（うさぎ柄の背景は置かない）。
- フォント一覧は `chat-css-generator/chat-core.js` と共通です。
