# QRコードメーカー

URL・Wi-Fi・連絡先などのQRコードを作る・読み取るツールです（入れた内容・画像はサーバーに送りません）。

中身をそのままQRコードに書き込む方式（このサイトを経由しない）なので、作ったQRコードに期限はありません。そのかわり、あとから飛び先は変えられません。ページの「ヒント・注意点」にもそう書いています。

| ファイル | 内容 |
|----------|------|
| `index.html` | 編集ページ（中身・形・色・ロゴ・保存） |
| `qr-core.js` | QRコードの符号化と描画（`window.QrCore`）。ほかのツールからも使えるように分けてある |
| `jsQR.min.js` | 読み取りに使う [jsQR](https://github.com/cozmo/jsQR) 1.4.0（Apache License 2.0。jsDelivr の縮めた版）。読み取るときに初めて読み込む |
| `jsQR-LICENSE.txt` | jsQR のライセンス（ページの「ヒント・注意点」からリンク） |

## できること

- **中身**：URL・文字 / Wi-Fi（`WIFI:T:…;S:…;P:…;H:true;;`）/ 連絡先（vCard 3.0。ふりがなは `X-PHONETIC-*`）/ メール（`mailto:`）/ 電話（`tel:`）/ SMS（`SMSTO:`）
- **形**：ドット（四角・角丸・丸・つながる丸）、角の目の外わく・中（四角・角丸・丸・葉っぱ）
- **色**：ドット・背景（透明にもできる）、グラデーション（ななめ・横・縦）、角の目だけ別の色
- **ロゴ**：まん中に画像を置く（長い辺 512px までに縮めて持つ）。下のドットを空けるかどうか、大きさ 10〜30%
- **保存**：PNG / SVG / JPG（256〜4096px）、PNG でクリップボードにコピー
- **注意の表示**：ドットが背景より明るい・色が近い・ロゴが大きすぎる・余白が少ない。描いたものを実際に読んで「読み取りOK」を出す（`BarcodeDetector` があるブラウザはそれで、ない Windows などは jsQR で）
- **読み取る**（上の切り替え。`#read` で直接開ける）：画像のドロップ・Ctrl+V の貼り付け・選択で読む。中身の種類（URL・Wi-Fi・連絡先など）を出し、Wi-Fi はネットワーク名・パスワードに分けて見せる。URL は自動で開かず、飛び先のドメインを見せてから「開く」。「この中身で作る」で作るほうに入れる

## `qr-core.js`

```js
const qr = QrCore.encode('https://…', 'M');   // 長すぎると err.code === 'too-long'（err.bytes にバイト数）
QrCore.draw(ctx, qr, style, 1024);            // canvas に描く
QrCore.svg(qr, style, 1024);                  // SVG の文字列
QrCore.coverage(qr, style);                   // ロゴの下で空けるデータのマスの割合
```

- 符号化は JIS X 0510 どおり。全体を数字・英数字・8bit（UTF-8）のどれか1つのモードで入れ、バージョンは入る一番小さいものを選ぶ。マスクは減点がいちばん少ないもの。
- 見た目はマス単位の SVG パスを作り、canvas では `Path2D` で同じパスを塗る（PNG と SVG の見た目がそろう）。ドットは1つのパスにまとめて塗るので、となり合うマスの間に細い線が出ない。
- ロゴの下を空けるときは、マスの区切りにそろえた奇数マスの正方形を真ん中に取り、そこのドットを描かない。
- `style` の項目はファイルの先頭のコメントにあります。

## 確かめたこと（2026-10-04）

- バージョン 1〜40 × 誤り訂正 L/M/Q/H を、それぞれ入る最大の長さで作り、zxing-cpp で全部読めた。数字・英数字モード、日本語（UTF-8）、ドット・目の形の全組み合わせも読めた。
- ロゴ（下を空ける）は、空けたマスの割合が M で 8.6%・Q で 14%・H で 15% なら読め、M 14%・Q 21% では読めなかった。注意は「誤り訂正で直せる割合（L 7%・M 15%・Q 25%・H 30%）の6割をこえたら少し大きめ、8割をこえたら大きすぎ」にしている。

## 読み取りの前処理

jsQR は丸いドットのQRコードが苦手なので、画像を何通りかに変えて順に試す（`scan()`）：そのまま → 半分に縮めて 1px ぼかす → 1/4 に縮める → 半分で 3px ぼかす → 2px ぼかす。このページで作れる組み合わせ（中身8種 × 誤り訂正4 × ドット4 × 目2 = 256 通り）を試し、どれも読めることを確かめた順番（2026-10-04）。「半分に縮めて 1px ぼかす」だけでも 256 中 237 が読める。

## 開発メモ

- `qr-core.js` を変更したら、`index.html` の `qr-core.js?v=` を上げてください。`jsQR.min.js` を差し替えたら、`index.html` の中の `jsQR.min.js?v=` を上げてください。
- 保存する設定は localStorage の `donnma-qr-v1`。Wi-Fi のパスワードとロゴの画像は保存しない。
- ページの見た目（パネル・設定欄など）は背景透過ツールの `index.html` と同じものです。
