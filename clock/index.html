時計・経過時間

OBS のブラウザソースで使える時計です。配信・録画を始めてからの時間を自動で数え、海外の時刻も並べられます。選んで URL をコピーするだけです。

🔌 OBS につないで反映つないでいません

OBS の「ツール → WebSocket サーバー設定」で、サーバーを有効にしてから使います（ポートとパスワードもそこにあります）。つなぐと、ここで変えた見た目を、選んだソースに反映できます。「すぐ反映」は変えるたびに、「ボタンで反映」は「📤 OBS に反映」か Ctrl+Enter を押したときに送ります。

🔍使い方
  1. 左で見た目と、出すもの（時計・もう1つの時刻・経過時間）を選びます。右の見本がすぐ変わります。
  2. 「📋 URL をコピー」を押します。
  3. OBS で ソースを追加 → ブラウザ を選び、URL に貼り付けます。幅・高さは見本の下に出ている大きさを目安にしてください。
  4. 置く場所と大きさは、OBS の画面でドラッグして合わせます。
  5. OBS につなぐと、URL を貼り直さなくても、ここで変えた見た目を OBS に反映できます（すぐ反映か、ボタンで反映かを選べます）。「＋ 今のシーンに時計のソースを足す」で、ソースを作るところからできます。
⏱️経過時間について
  • 配信・録画・リプレイバッファ・仮想カメラを始めてからは、OBS が知らせてくる開始・停止で数えます。OBS の外（ふつうのブラウザ）では数えません。
  • OBS を開き直したり、ソースを読み込み直したりしても、配信中なら続きから数えます。
  • ブラウザソースの「ページ権限」が「アクセス権なし」だと、開始・停止が届きません。うまく数えないときは、ソースのプロパティで確かめてください。
  • 録画を一時停止している間は、経過時間も止まります。
  • ソースを表示してからは、ソースの「シーンがアクティブになったときにブラウザの表示を更新」をオンにすると、シーンに切り替えるたびに 0 から数え直せます。
💡ヒント・注意点
  • 時計は、OBS を動かしているパソコンの時刻を使います。
  • 設定はすべて URL に入っているので、保存やログインは要りません。見た目を変えたいときは、ここで作り直した URL に貼り替えてください。
