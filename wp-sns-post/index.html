WordPress プラグイン

SNS Post

WordPress で記事を公開すると、Bluesky・Threads・X・Facebook ページ・Discord へ自動で投稿するプラグインです。外部のサービスを通さず、サイトから各 SNS へ直接送ります。

ダウンロード（GitHub Releases） GitHub

無料・WordPress 6.6 以上・PHP 7.4 以上・GPLv2 or later

できること

公開したら自動で投稿

記事を公開すると、約1分後に5つの送り先へ投稿します。更新しただけでは送りません。

外部サービスを通さない

各 SNS の API へサイトから直接送るので、サイトのデータや SNS の権限をほかのサービスに預けずに済みます。

送り先ごとのひな形

{message}・{url}・{tags} などを差し込んで、送り先ごとに投稿の形を決められます。

ハッシュタグを選べる

送り先ごとにハッシュタグを決め、記事ごとに付けたり外したりできます。

送る前にプレビュー

記事の編集画面で、送り先ごとに実際に送る本文と文字数を確かめられます。

失敗してもやり直す

失敗したら10分おきに3回まで試し、だめなら Discord に知らせます。記事の画面から「今すぐ送る」でやり直せます。

送り先

送り先つなぎ方文字数料金
Blueskyアプリパスワード300無料
Threadsログインしてつなぐ（トークンは毎週自動で延長）500無料
X開発者コンソールの4つの鍵280（全角は2、URL は23と数える）API の従量課金
Facebook ページログインしてつなぐ（期限なし）なし無料
DiscordWebhook の URL1900無料

Bluesky・Threads・Facebook には、記事のリンクのカードが付きます。X と Discord は、本文の URL からカードが出ます。文字数を超えるときは、URL やハッシュタグは残して、投稿文の方を短くします。

Threads と Facebook は、Meta for Developers で1つのアプリを作ってつなぎます。手順は GitHub の README にあります。

インストール

  1. Releases から zip をダウンロードします。
  2. WordPress の管理画面で「プラグイン」→「新規追加」→「プラグインのアップロード」を開き、zip を選んで有効化します。
  3. 「設定」→「SNS 投稿」の Bluesky・Threads・X・Facebook・Discord のタブで、それぞれつないで「確かめる」を押します。
  4. 「基本」のタブで送り先にチェックを入れ、テストモードを外します。

入れた直後はテストモードで、どこにも送りません。ほかの自動投稿のプラグインから乗り換えるときは、そちらを止めてからテストモードを外してください。

ひな形とハッシュタグ

各送り先のタブで、投稿のひな形を決められます。いちばん新しい記事で埋めた見本も出ます。

差し込み中身
{message}記事ごとの投稿文（空なら記事のタイトル）
{title}記事のタイトル
{url}記事の URL
{excerpt}記事の説明文
{hashtags}その送り先の「ハッシュタグ」欄の中身
{tags}記事のタグをハッシュタグにしたもの
{categories}・{site}カテゴリー・サイトの名前

「ハッシュタグ」欄に #サイト名 {tags} と書けば、決まったタグと記事のタグを一緒に付けられます。Discord にはハッシュタグの機能がなく、Threads はトピックになるタグが1つだけなので、送り先ごとに分けるのがおすすめです。

記事ごとの投稿文とプレビュー

記事の編集画面の右側「SNS 投稿」で、記事ごとに次のことができます。

  • 共通の投稿文を書く（空なら記事のタイトル）
  • 「送り先ごとに別の文にする」で、X だけ短く、のように書き分ける
  • 「ハッシュタグを付ける」で、送り先ごとに外す
  • 「この記事は SNS に投稿しない」
  • 「送る本文をプレビュー」で、送り先ごとの本文と文字数を確かめる（保存していない変更もそのまま反映）

公開したあとは、送り先ごとの結果（投稿済み・失敗とその理由）と、投稿へのリンクが出ます。

Discord の通知

Discord には、記事の公開のほかに、次のことも知らせます。用途ごとに送り先のチャンネルを分けられます。

  • フォームの送信（Contact Inbox は対応済み。ほかのフォームはフック dsp_form_submitted で）
  • コメント（スパム・ゴミ箱は除く）
  • 投稿をあきらめたとき・Threads のトークンを延ばせなくなったとき

本文に @everyone などが書かれていても、メンションの通知は飛びません。

よくある質問

無料で使えますか？

プラグインは無料です（GPLv2 or later）。Bluesky・Threads・Facebook・Discord への投稿も無料ですが、X の API は従量課金で、リンク付きの投稿は1件ごとに料金がかかります。

ほかの自動投稿のプラグインから乗り換えられますか？

はい。入れた直後はテストモードで、どこにも送りません。前のプラグインを止めてからテストモードを外してください（同じ記事が二重に投稿されるのを防ぐため）。

更新するたびに投稿されませんか？

されません。公開していなかった記事を公開したときだけ送ります。送り直したいときは、記事の編集画面の「もう一度送る」を使います。

Threads のトークンの期限は？

60日ですが、プラグインが毎週自動で延ばします。延ばせなくなったときは管理画面と Discord に知らせます。

ハッシュタグが使えない送り先はありますか？

Discord にはハッシュタグの機能がありません。Threads はトピックになるタグが1つだけです。送り先ごとにハッシュタグ欄を分けられるので、Discord は空にしておくのがおすすめです。

動作環境・注意

  • WordPress 6.6 以上（ブロックエディター）、PHP 7.4 以上
  • トークンはサイトのデータベースに置きます（設定画面には出しません）。使わなくなったら SNS 側でも取り消してください
  • WP-Cron で送るので、アクセスのほとんどないサイトでは送るのが遅れることがあります
  • 管理画面は日本語だけです
  • 個人で作ったものです。サポートや不具合の対応はお約束できません

ライセンス

GPLv2 or later です。
