# YouTube チャプターメーカー

YouTube の概要欄に入れるチャプター（目次）を作るツールです。メモのタイムスタンプを整えて、YouTube がチャプターとして認める条件に合っているかを確かめます。

| ファイル | 内容 |
|----------|------|
| `index.html` | 画面と処理（1ファイル。動画は YouTube の IFrame Player API で見る） |

## できること

- **まとめて貼る**：1行に1つ、時刻のある行だけ読む（「0:00 内容」「[12:34] 内容」「12:34〜 内容」「内容 12:34」「1:02:30」「3分20秒」、全角の数字・：も可）。時刻をかこむかっこ（`[ ]` `【 】` `( )` `（ ）`）と、時刻のまわりの `- | ・ 〜 :` は外す。内容の中のかっこは残す。入れかえ／下に足す
- **行で入れる**：時刻（`1:23`・`01:02:03`・`83秒`・`1分23秒`）と内容。時刻の欄を出ると `1:23` の形にそろえる。内容の欄で Enter → 次の行（なければ足す）。↑ で入れかえ、時刻の順に並べる
- **動画を見ながら**：URL（watch?v= / youtu.be / live / shorts / embed）を開き、「今の時刻で区切る」（M キー。入力欄の外で）で今の秒を足して並べる。▶ でその時刻へ飛ぶ。−5秒・+5秒
- **YouTube の条件**：0:00 から・3つ以上・小さい順・同じ時刻がない・次まで 10 秒以上・動画の長さ以内（動画を開いたとき）。内容が空なら注意だけ。「0:00 の行を足す」「並べる」「同じ時刻のあとの行を消す」はボタンで直す
- **書き出し**：`0:00 / 1:02:03` か `00:00 / 01:02:03`（1時間を超えるものがあれば全部を時間つきにそろえる）、時刻と内容のあいだ（空白・ - ・ | ・全角の空白）、上に付ける見出し。文字数（概要欄は 5000 文字まで）
- **全部の時刻をずらす**：`-30`・`+1:05` など。0:00 の行は動かさない
- **進行表から**：配信スケジュールメーカー（`../schedule/`）の「1日」の進行表（localStorage `donnma-schedule` の `tday`）があれば、配信を始めた時刻を引いてチャプターにする
- 入れたものは localStorage（`donnma-chapter`）に覚える

## 開発メモ

- 条件は YouTube のヘルプにある「最初が 0:00・3つ以上・各 10 秒以上・小さい順」。書き出しは時刻の読める行を入れた順のまま出す（並べるのはボタンで）。
- 「0:00」だけの行（はじめに置く行）は、入れかえの確認で「入れてある」と数えない。
