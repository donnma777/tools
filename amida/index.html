あみだくじ

参加者と結果を入れるだけで、あみだくじを作れます。横線を足してから始めたり、結果を隠して1人ずつ開けたり、全員まとめて開けたり。ブラウザでそのまま使えるほか、OBSの配信画面にも出せます。順番決め・チーム分け・罰ゲームに。

    🪜 あみだくじ（ブラウザソース用）
    🛠 操作パネル（カスタムブラウザドック用）

    「あみだくじ」はOBSの「ソース ＋ → ブラウザ」に貼り付けます（幅1920・高さ1080）。「操作パネル」はOBSのメニュー「ドック → カスタムブラウザドック」に貼り付けると、OBSの中でくじを作ったり開けたりできます。くわしくは下の「使い方」へ。

    ※ OBSに入れる機能（ブラウザソース・ドック・OBS接続）は、PCのOBS Studio向けです。スマホでは、このページでそのまま使えます。

    OBS接続（Chromeから操作するとき）

    OBSの「ツール → WebSocketサーバー設定」で「WebSocketサーバーを有効にする」をオンにし、「接続情報を表示」のポートとパスワードを入れてください。同じPCのChromeで開けると、OBSのブラウザソースでも同じように開きます。ドックで操作するときは不要です。

    ● 未接続

    🪜 あみだくじの流れ

    1. 左の「参加者と結果」に、上に並ぶ名前と、下に並ぶ結果を1行ずつ書きます（結果のサンプルも使えます）。
    2. 「🎲 くじを作る」 を押すと、横線が引かれます。結果は並びを混ぜて隠しておきます。
    3. 始める前に 「➕ 横線を1本足す」 を押したり、プレビューの 縦線と縦線の間をクリック したりすると、横線を足せます。参加者やコメントの指示で足すと盛り上がります。
    4. プレビューの 名前や結果の札をドラッグ すると、2枚を入れ替えられます。結果の札は「？」で隠したまま入れ替わるので、配信で「どれにする？」と混ぜる演出にも使えます（開け始める前まで）。
    5. プレビューの下の 名前（またはプレビューの名前の札）を押すと、その人の線をたどって結果をめくります。「🎉 全員まとめて開く」 なら、残りの人を順番に（または一斉に）開けます。
    6. 終わったら 「🖼 画像で保存」 で結果を画像にしたり、「結果」の 「📋 コピー」 でテキストにしたりできます。

    🎥 OBSでの使い方

    1. 右の「OBSに入れる」で あみだくじ の「URLをコピー」を押し、OBSで ソース ＋ → ブラウザ を追加してURLに貼り付けます（幅 1920・高さ 1080）。
    2. 同じく 操作パネル の「URLをコピー」を押し、OBSのメニュー ドック → カスタムブラウザドック を開いて、ドック名（例: あみだくじ）とURLを入れて「適用」します。
    3. ドックでくじを作ったり開けたりすると、配信画面のあみだくじも一緒に動きます。
    4. Chromeで操作するときは、OBSの「ツール → WebSocketサーバー設定」でサーバーを有効にし、右の「OBS接続」にポートとパスワードを入れて「接続」を押します。
    5. 効果音を配信に乗せるときは、ブラウザソースのプロパティで 「オーディオをOBSで制御する」 にチェックを入れると、音量ミキサーで音量を調整できます。

    💡 ヒント・注意点

    • 公平さ：「🪜 くじの作り方」の 結果の並びを混ぜる がオンなら、くじを作るたびに結果の並びをランダムに混ぜます。横線をどう足しても、札をどう入れ替えても、だれがどれに当たるかは公平です。
    • 横線を隠しておく をオンにすると、自動で引いた横線に覆いをかけます（手で足した線だけ見えます）。紙のあみだくじのように、どこへ行くか分からないまま楽しめます。
    • 横線を足したり札を入れ替えたりできるのは、だれかを開ける前までです。開け始めたあとに最初からやり直すときは 「↺ 同じくじで最初から」、くじごと変えるときは 「🎲 作り直す」 を押します。
    • 参加者の人数を変えると、くじは作り直しになります（名前や結果の文字を直すだけなら、そのままです）。
    • 操作パネルでは スペースキー でも「くじを作る」「次の人を開ける」ができます。
    • OBSを使わないときは、プレビューの 「⛶ 大きく表示」 で画面いっぱいに広げて、画面共有や会場のモニターに映せます。「↗ 別タブで開く」 ならあみだくじだけのタブを開けます（音は、そのタブを一度クリックすると鳴るようになります）。
    • OBSであみだくじのソースを選んで 「対話」 を開き、名前や縦線の間をクリックしたり、札をドラッグしたりしても操作できます。
    • 参加者・結果・見た目は、このブラウザに自動で保存されます（OBSのドックとブラウザソースは同じ保存場所を使います）。別のPCに移すときは「ファイルに保存」を使ってください。
