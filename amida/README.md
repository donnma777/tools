# あみだくじ

ブラウザでそのまま使えて、OBSの配信画面にも出せるあみだくじです。参加者と結果を入れて「くじを作る」を押し、横線を足してから、1人ずつ・全員まとめて開けます。

| ファイル | 内容 |
|----------|------|
| `index.html` | 編集・操作ページ（`?dock=1` でOBSのカスタムブラウザドック向けの表示） |
| `view.html` | OBSのブラウザソースに入れる表示ページ（1920×1080 の canvas。ウィンドウの大きさに合わせて拡大・縮小） |
| `amida-core.js` | くじ `A`・見た目 `S` の初期値と読み込み、横線の引き方・たどり方、保存、canvas への描画（`window.AmidaCore`） |

## くじのデータ（`A`）

- `players`・`prizes`：上に並ぶ名前と、下に並ぶ結果（2〜20人）。
- `board`：`makeBoard()` で作るくじ。`rungs` が横線（`c` 本目と `c+1` 本目の間、高さ `y` は上から 0〜1。`u` は手で足した線）、`order[列]` がその列の下に置く結果の番号。人数が変わると `null` に戻す（作り直し）。
- `opens`：開けた記録（`p` 番目の人を時刻 `at` に開けた。`d` はたどり始めるまでの待ち、`m` は開け方 `one`／`seq`／`all`）。
- だれがどこに着くかは `trace()` で毎回計算する（横線を上から順に見て、今の縦線につながる線を渡る）。

## しくみ

- **公平さ**：`S.shufflePrizes` なら、くじを作るたびに結果の並び `order` を混ぜる。横線をどう足しても、だれがどれに当たるかは公平になる。
- **横線**：自動で引く線は 24 段の高さから選び、となりのすき間と同じ段・同じすき間の隣の段には引かない。手で足す線は、となりの線と `GAP`（0.03）以上あける。足せるのは開け始める前まで（`rungError()`）。
- **演出**：表示ページは `opens` に新しい記録が届いたら、`at + d` の時刻から `traceSec` 秒で線をたどり、着いたら結果をめくる。開き直したときにもうあった記録は、演出なしで出来上がった絵にする。くじを作り直したら横線を左から順に伸ばす。
- **描画**：`draw()` は 1920×1080 の座標で描く。表示ページと、編集ページの「画像で保存」（PNG）が同じ関数を使う。
- **同期**：くじと見た目はブラウザの localStorage（`donnma-amida-v1`）に保存する。ドックとブラウザソースは同じOBSの中なので、`storage` イベントで同期する。Chrome から操作するときは obs-websocket の `emit_event`（`donnmaAmidaUpdate`）で送る。
- **マウス・タッチ**：OBSでソースを「対話」で開いたときや別タブでは、名前をクリックすると開け、縦線の間をクリックすると横線を足せる（`hitTest()`）。プレビューでの操作は `postMessage`（`am-click`・`am-swap`）で編集ページに渡す。
- **札の入れ替え**：`S.dragSwap` なら、名前・結果の札をドラッグで入れ替えられる（`swap()`。開け始める前だけ）。くじを作ったあとの結果は、隠したまま `order` だけを入れ替える。表示ページは前の状態と比べて2枚だけ入れ替わっていたら、札がすべって入れ替わる演出を流す。
- 効果音は WebAudio で鳴らしています（音声ファイルなし）。

## 開発メモ

- 確認はOBSのドックで `confirm()` が出ないことがあるので、ページの中の確認（`common/ask.js` の `ask()`）を使っています。
- フォント一覧は `chat-css-generator/chat-core.js` にあります。
- `amida-core.js` か `chat-css-generator/chat-core.js` を変更したら、`index.html`（script と iframe の `view.html?v=`）と `view.html` の `?v=` を上げてください。
- 編集ページのスタイルの前半（ヘッダー・パネル・設定欄など）はルーレットの `index.html` と同じものです。
