フォルダツリーメーカー

字下げで書いた一覧や、パソコンのフォルダから、├── のツリーを作ります。README・ブログ・質問に貼る構成図に。ファイルはどこにも送信しません。

✏️ 書くところ
ここに落とすと読み込みます

字下げはスペースでもタブでも。Tab で字下げ、Shift+Tab で戻します（何行かまとめても）。 # コメント は名前の右に出します。名前の後ろに / を付けるとフォルダになります。

📂 フォルダから作る
ドロップでも入ります。中身はブラウザで読むだけで、送信しません。
🌲 できあがり
🔍使い方
  1. 左に、1行に1つずつ名前を書きます。中に入るものは字下げ（スペースかタブ）します。
  2. 右にツリーができます。「線の形」や「並べ方」を選んで、「コピー」で貼りつけられます。
  3. パソコンのフォルダから作るときは「フォルダを選ぶ」か、フォルダを左にドロップします。左に字下げの一覧が入るので、そこで消したり、コメントを足したりできます。
  4. 前に作ったツリー（├── や |--、- のリスト）を貼っても読めます。「字下げに直す」で書き直しやすい形にします。
💡こんなときに
  • GitHub の README に、リポジトリの中身の説明を書くとき（「Markdown 用にコピー」がそのまま使えます）。
  • ブログ・Qiita・Zenn の記事や、質問の掲示板・AI に、フォルダの構成を伝えるとき。
  • サイトのページ構成や、資料の置き場所の決まりをまとめるとき。
  • X（Twitter）などに貼るときは画像（PNG）にすると、線がずれません。
⚙️線がずれるとき
  • │ や ─ は、フォントによって半角の幅にも全角の幅にもなります。英語のフォント（GitHub など）では「ふつう」がそろいます。
  • MS ゴシックなど日本語のフォントで見る場所（Excel・メモ帳・掲示板など）では、「全角・日本語のフォント向け」にするとそろいます。「日本語のフォントで見る」で確かめられます。
  • どこでも同じに見せたいときは、「記号だけ」か画像（PNG）が確実です。
  • フォルダを選ぶとき、ブラウザに「アップロード」と出ることがありますが、ファイルは送られません（名前を読むだけです）。中身が空のフォルダは「選ぶ」では出ず、ドロップだと出ます。
