# フォルダツリーメーカー

字下げで書いた一覧や、パソコンのフォルダから `├──` のツリーをテキストで作るツールです。ファイルはどこにも送りません。

| ファイル | 内容 |
|----------|------|
| `index.html` | 画面と処理（1ファイル。外部のライブラリは使わない） |

## できること

- **書いて作る**：1行に1つずつ書き、字下げ（スペース・タブ）で中に入れる。`Tab`／`Shift+Tab` で字下げ（何行かまとめても）。`  # コメント`（`//`・`<-`・`←` も）は名前の右に出す。後ろに `/` を付けるとフォルダ
- **貼って読む**：`├──`・`|--`・`+---`（Windows の `tree /a`）・全角の `├─`・`- ` のリストも読める。「字下げに直す」で2文字ずつの字下げに書き直す
- **フォルダから作る**：「フォルダを選ぶ」（`webkitdirectory`）かドロップ（中をたどるので空のフォルダも出る）。外すもの（名前、`*` 可）・いちばん上の `.gitignore`（`!`・`/` 始まり・`**` に対応）・`.` で始まるもの。20000 個まで
- **線の形**：ふつう・短め・角が丸い・太い・全角（日本語のフォント向け）・記号だけ・Windows・字下げだけ
- **出し方**：並べ方（書いた順／フォルダが先の名前順／名前順）・フォルダの `/`・アイコン（📁📄）・深さ・いちばん上に `.`・コメントの位置そろえ・フォルダだけ・最後に数
- **書き出し**：コピー・Markdown 用（` ```text ` で囲む）・.txt・PNG（暗い色／明るい色）
- 書いた内容と設定は localStorage（`donnma-tree`、50 万文字まで）に覚える

## 開発メモ

- 読むときは、行の頭の線や `- ` を取った長さで深さを決める（Python のインデントと同じく、前の行より深いかどうかだけを見る）。`+page.svelte` のような名前を線と間違えないよう、`+`・`-` は後ろに `-` か空白があるときだけ線とみなす。
- 作ったツリーを貼り直すと、どの線の形でも同じものに戻ることを確かめてある。
- コメントの位置そろえは全角を2文字として数える。「全角」の線の形と「日本語のフォントで見る」では、罫線も全角として数える。
