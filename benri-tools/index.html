Chrome 拡張機能

便利ツール拡張機能まとめ

広告ブロック・強制ダークモード・スクリーンショットの3つを、単体でも、1つにまとめた統合版でも使える Chrome 拡張機能です。

ダウンロード（GitHub）

無料・Chrome 109 以降（パソコン）

入っている拡張機能

フォルダ名前機能
便利ツール/便利ツール（統合版）広告ブロック・ダークモード・スクリーンショットを全部
広告ブロック/広告ブロッカー広告ブロックだけ
強制ダークモード拡張機能/強制ダークモードダークモードだけ
スクリーンショット/スクリーンショットスクリーンショットだけ

全部使うなら統合版の 便利ツール を、1つだけ使いたいなら単体のものを入れてください。

できること

広告ブロック

通信の段階で広告をブロックし、ページに残った広告の枠も隠します。サイトごとに除外できます（サブドメインもまとめて）。

強制ダークモード

明るいページを暗い色に変えます。サイトごとのオン・オフと、全部のサイトへの一括設定ができます。もともとダークに対応したサイトは自動で飛ばします。

表示モードの確認

このタブだけ、ページから見たライト/ダークの設定を切り替えて、見え方を確かめられます（サイトを作る人向け）。

スクリーンショット

見えている範囲か、ページ全体をスクロールしながら撮って1枚の PNG に。固定ヘッダーは2枚目から自動で隠します。

インストール

  1. GitHub の緑の「Code」→「Download ZIP」でダウンロードして展開します。
  2. Chrome で chrome://extensions を開き、右上の「デベロッパー モード」をオンにします。
  3. 「パッケージ化されていない拡張機能を読み込む」を押し、使いたい拡張機能のフォルダ（例: 便利ツール）を選びます。

いくつか入れるときは、手順 3 をくり返してください。

使い方のコツ

  • 広告ブロックのオン・オフや除外の設定は、開いているタブにすぐ効きます。読み込み済みの広告まで消すには、そのタブを再読み込みしてください（ポップアップにも案内が出ます）。
  • ポップアップの「現在のサイト」に、そのサイトを除外しているかどうかが出ます。除外の一覧は設定ページで見られます。
  • スクリーンショットのファイル名は screenshot-visible-日付-時刻.png（見えている範囲）・screenshot-fullpage-日付-時刻.png（ページ全体）です。

よくある質問

無料で使えますか？

はい、無料です。

広告ブロックでページが崩れたときは？

ポップアップからそのサイトを除外して、タブを再読み込みしてください。

表示モードを試すと、黄色いバーが出ます

「デバッグされています」という Chrome のバーで、この機能の仕組み上どうしても出ます。タブを閉じるかページを離れると、自動で元に戻ります。

Chrome ウェブストアにはありますか？

今はありません。GitHub からダウンロードして、Chrome に読み込んで使います。

動作環境

  • Google Chrome 109 以降（パソコン）
  • 使う権限: 通信のブロック・保存・タブ・ページへの書き込み・ダウンロード・オフスクリーン・デバッガー（機能によって違います）
