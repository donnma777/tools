スコアアタック集計

大会の予選で、参加者ごとの点数（タイム）を入れると、合計や順位を自動で出します。OBS に入れれば、点数を入れるたびに順位表がその場で変わります。

✏️点数を入れる

Enter で下へ、Tab で右へ動きます。Excel やスプレッドシートからコピーした表は、貼りたいところの欄に貼り付けるとまとめて入ります（1行目が曲名なら、曲名も入ります）。

📺 OBS に出す

↗ 開く

OBS では、点数を入れた人が光り（NEW）、入りきらないときは 8 秒ごとにページをめくります。下の2つのどちらかで、ここで入れた点数を OBS に届けます。

① このページを OBS の「カスタムブラウザドック」で開く（同じ OBS の中なので、そのまま届きます）。
② Chrome などで開いたまま、下で OBS につなぐ。

🔌 OBS につなぐ（Chrome などで使うとき）つないでいません

OBS の「ツール → WebSocket サーバー設定」で、サーバーを有効にしてから使います。つないでいる間は、点数を入れるたびに OBS の表示が変わります。

🔍使い方
  1. 課題曲と参加者を入れます。名前は「名前をまとめて入れる」で1行ずつ、Excel の表なら貼り付けでも入れられます。
  2. 大会で、点数かタイムか・順位の決め方・本戦に進む人数を決めます。
  3. プレイが終わるたびに点数を入れると、右の順位表がすぐ変わります。
  4. OBS に出すときは「📋 URL をコピー」してブラウザソースに貼り、このページを OBS のドックで開くか、「OBS につなぐ」でつなぎます。
  5. 予選が終わったら「🏆 通過者をコピー」して、トーナメント表メーカーの参加者に貼れば、順位の順にシードが付きます。
📊順位の決め方
  • 合計：全部の曲の点数（タイム）を足します。まだやっていない曲は 0 点です（タイムは、全部の曲をやった人を先に並べます）。
  • 曲ごとの順位の合計：曲ごとに順位を付けて、その順位を足します。小さいほど上です。曲によって点数の大きさが違っても、同じ重さで比べられます。まだやっていない曲は最下位として数えます。
  • 理論値比：曲ごとに「点数 ÷ 理論値」を出して平均します。理論値を入れていない曲は、その曲のいちばん高い点数を 100% にします（点数のときだけ）。
  • 同じ値のときは同じ順位にして、1位を取った曲の数が多い人を上に並べます。
💡ヒント・注意点
  • 点数は「1,000,000」のようにカンマが入っていてもかまいません。タイムは「1:23.45」「83.45」のどちらでも入れられます。
  • 入れた点数はこのブラウザに覚えておきます。別のパソコンで使うときは、同じように入れ直してください。
  • 参加者が多くて1枚に入りきらないときは、見本の ◀ ▶ でページを切り替えて、ページごとに PNG で保存できます。OBS の URL の最後に #page=1 を付けると、そのページだけを出します。
