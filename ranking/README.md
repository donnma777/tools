# スコアアタック集計

大会の予選（スコアアタック）で、参加者ごとの点数やタイムから順位を出すツールです。OBS に入れると、点数を入れるたびに順位表がその場で変わります。

| ファイル | 内容 |
|----------|------|
| `index.html` | 作るページ。点数の表・課題曲・大会の設定・見た目、見本（PNG・コピー）、OBS につなぐ |
| `view.html` | OBS に入れるページ（noindex）。中身は localStorage か、obs-websocket で届いたもの |
| `ranking-core.js` | 順位の計算と canvas への描画（`window.RankingCore`） |

## できること

- **点数の表**：参加者 × 課題曲（20曲まで・300人まで）。Enter で下（いちばん下なら人を足す）。Excel・スプレッドシートの表を貼ると、貼った欄から右下へ入る。名前の欄に貼り、1行目に数が1つもなければ、その行を曲名として使う。名前だけをまとめて入れる欄もある
- **点数かタイムか**：点数（高いほど上。カンマ・空白・全角も可）／タイム（短いほど上。`1:23.45`・`83.45`・`1'23"45`）
- **順位の決め方**
  - 合計：やっていない曲は 0。タイムは、全部の曲をやった人を先に並べる
  - 曲ごとの順位の合計：曲ごとに順位（同じ値は同じ順位）を付けて足す。やっていない曲は「参加者の数」位
  - 理論値比（点数だけ）：曲ごとに 点数 ÷ 理論値 × 100 を出して平均。理論値がない曲は、その曲のいちばん高い点数を 100%
  - 同じ値は同じ順位。並びは、1位を取った曲の数が多い順 → 入れた順。1曲もやっていない人は順位なしで下へ
- **本戦ライン**：上位○人の行に色を付け、すき間に「ここまで本戦へ」の線。「通過者をコピー」で、通過した人の名前を順位の順に1行ずつ（トーナメント表メーカーの参加者にそのまま貼れる）
- **見た目**：ポップ・シンプル・ネオン・和風、色、横長 16:9／縦長 4:5、背景（テーマ・透明）、曲ごとの順位を出す。1〜3位にメダル。入りきらないときはページに分ける（PNG はページごと、または全部）
- **OBS**：最後に点数を入れた人を 8 秒光らせる（NEW）。その人が別のページなら、そのページを出して止める。入りきらないときは 8 秒ごとにページをめくる。`view.html#page=2` でページを決める

## 同期（トーナメント表メーカーと同じ作り）

- 中身は localStorage（`donnma-ranking-v1`）。作るページを OBS のカスタムブラウザドックで開けば、同じ OBS の中なので `storage` イベントで view.html に届く
- Chrome などで作るページを開いたときは、obs-websocket v5 につなぎ、obs-browser の `emit_event`（`donnmaRankingUpdate`、中身はデータそのもの）で送る。view.html は受け取ったものを自分の localStorage にも保存する
- OBS の接続先は `donnma-ranking-obs`。前につないでいたら、開いたときにつなぎ直す（OBS のドックの中ではつながない）

## 開発メモ

- 描画は配信スケジュールメーカー（`schedule/schedule-core.js`）と同じ配色・背景の作り。テーマを足すときは `THEMES`・`palette`・`drawBg` に足す。
- 表の高さは 1行 40〜72（基準 1080 のとき）。入りきらない数は次のページへ。`draw()` は `{ pages, page, perPage }` を返す。
